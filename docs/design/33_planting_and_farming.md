# 植林と畑

作成: 2026-09-26。§9 のとおり軽い形で実装した（2026-09-26）。

## 1. 目的

ユーザー（2026-09-26）: 「植林や農業は能力がなくてできない、と断られてしまう。できるようにならないか」

今は断るのが正しい: ブリッジに苗木を植える・耕す・種をまく・収穫する行動がなく、それを完了条件にできる述語もない（返答は完了条件で書けない頼みを断る決まり）。葉から苗木、草から種を取る入手元もない（葉は棒とリンゴのドロップの数字が当てにならないので入手元から外している）。

## 2. 形（ほかの目標と同じ三層）

- Gemini: 新しい述語で目標と中目標を書く。視聴者の「木を植えて」「畑を作って」も中目標として引き受けられる
- ブリッジ: 世界から判定し、足りないものを分解し（苗木、種、クワ）、候補を出し、1 つずつ実行する
- Jev: 候補から選ぶ（今までどおり）

## 3. 述語（中目標の完了条件になれる）

- **`planted(sapling, n)`**: 家のまわり（家から 6〜24 m）に、自分が植えた木が n 本ある。植えた場所はブリッジが覚える（`state.plantings`）。数えるのはその場所に苗木か、育った木（原木）があるもの。苗木の種類は何でもよい（`sapling` はグループ: oak_sapling など）か、種類を指定
- **`farmed(crop, n)`**: 家のまわりの畑に、作物が植わった耕地が n マスある（crop は wheat。にんじん・じゃがいも・ビートルートは持っていれば同じ形で）。世界から数える（耕地の上の作物ブロック）
- 収穫は今の `have(wheat, n)` / `have(bread, n)` / `have(food, n)` のまま: 育ちきった作物（小麦なら age 7）を入手元に足し、収穫したら同じ場所に種をまき直す

## 4. ブリッジ

- **入手元（solver）**
  - 苗木: 葉を素手で壊す（1 枚あたり 5% ほど。1 本の木に葉は数十枚あるので、木 1 本から数個）。葉を入手元に足すのは苗木だけ（棒とリンゴは今までどおり数えない）
  - 種（wheat_seeds）: 草（short_grass / tall_grass）を壊す（12.5%）
  - クワ: レシピ（今の knowledge で作れる）
  - 小麦・にんじん・じゃがいも: 育ちきった作物を壊す（畑があれば）
- **場所**: 家から 6〜24 m の平らな草・土の地面。家、建物（25）、扉の前の通り道、ほかの植えた場所の近くには置かない。木は 1 本ずつ 4 m 以上離す（育つのに要る空き）。畑は 1 か所にまとめる（最初の畑の隣に広げる）。近くに水があればその 4 m 以内を選ぶ（耕地が湿って速く育つ。なくても植えられる）
- **行動（primitives）**: `plant`（苗木を地面の上に置く）、`till`（クワで土を耕地にする）、`sow`（耕地に種をまく）、`harvest`（育ちきった作物を壊して、すぐにまき直す）。どれも今の `place_at` / `dig` と同じ長さの 1 手。夜と家に籠もっている間は出さない（今の安全の決まりのまま）
- **木を切るとき**: 自分が植えた木を切ったら、落ちた苗木をその場所に植え直す候補を出す（切るだけで減らない）
- **道具モード・技**: 道具 `plant` / `till` / `sow` / `harvest`（場所を省けばブリッジが選ぶ）、技の `t.plant(...)` など。安全の決まりはブリッジの側
- **世界の記憶**: 植えた場所（`state.plantings`）と畑（`state.farm`: 耕地のセル）を `state.json` に。`/observe` の要約に「植えた木 n 本（育った m）、畑 k マス（収穫できる j）」

## 5. Python

- `GoalPredicate.PLANTED` / `FARMED`、スキーマと説明、`CONDITION_PREDICATES` に入れる（中目標と手順に使える）
- 「できること」（ABILITIES）に植林と畑を足す（返答が断らなくなる）
- 道具の一覧（tool_catalog）、技の API の説明
- 実況と目標ボード: 述語の日本語の名前（「木を植える」「畑」）

## 6. やらないこと（今は）

- 水を運ぶ（バケツは鉄 3 つ。畑の水は近くの水だけ）
- 骨粉で育てる、動物を増やす（エサで繁殖）、かぼちゃ・スイカの茎、サトウキビを植える
- 畑の柵（動物に荒らされる）。必要なら 25 の建物（fill の柵）で

## 7. 決めてほしいこと

1. 範囲: 植林と小麦の畑（にんじん・じゃがいもは持っているときだけ）から始める。動物の繁殖は後。これでよいか
2. 場所: 家から 6〜24 m に、ブリッジが選ぶ（Gemini は場所を書かない）。25 の地図（`map` と C7 のようなマス）で Gemini が場所を選べるようにもできるが、最初はブリッジに任せる。これでよいか
3. 水: 近くに水があればそこを選ぶだけ（運ばない）。これでよいか
4. 植え直し: 自分が植えた木を切ったら植え直す、収穫したらまき直す、を必ずする。これでよいか
5. 苗木と種の集め方: 葉と草を壊して集める（少し時間がかかる）。よいか

## 8. 検証

- 単体テスト（ブリッジ）: 述語の判定（植えた場所に苗木か木、耕地の作物）、場所の選び方（家・建物・通り道を避ける、木の間隔）、入手元（葉 → 苗木、草 → 種、育った作物 → 小麦）、植え直しの候補、夜は出さない
- 単体テスト（Python）: 述語のスキーマと解析、中目標の条件になれる、できることの文
- 実機: 「木を植えて」「畑を作って」を引き受けて、家のまわりに植える・耕す・まく・育った小麦を収穫してパンにする

## 9. 実装（2026-09-26、軽い形）

ユーザー「B（技）でできるようになったと思っていた」→ 技は道具の組み合わせなので、足りなかったのは語彙（述語）と 1 手の道具だった。やり方は道具モードの Gemini（技）に任せ、ブリッジには語彙・判定・道具・安全の決まりを足した。候補モードでも最低限は動く。

- ブリッジ `farming.mjs`: `planted(sapling|種類, n)`（`state.plantings` の場所に苗木か原木）、`farmed(crop, n)`（家のまわりの耕地の作物、育ちきった数も）。場所の選び方 `plantSpot`（家から 6〜24 m、木から 4 m）、`tillSpot`（今の畑の隣 → 水の近く → 平らな所）、`sowSpot`、`farmRefusal`（家・建物とそのまわり 1 マス、家に近すぎる所）
- 述語は目標・中目標の条件・技の expects（`+N` も）になる
- 行動と道具: `plant` / `till` / `sow`（場所を省くとブリッジが選ぶ）。`dig` は草・作物・苗木・花も掘れる（収穫、種）
- 入手元: 苗木は葉、種は草（確率。掘って落ちなくても失敗にしない）。グループ `sapling`、`hoe`
- 候補モード: planted は苗木があれば植える候補、なければ集める。farmed は種 → 空いた耕地にまく → クワ → 耕す
- Python: `GoalPredicate.PLANTED / FARMED`、今使える述語（家があるとき）、説明、できること（「畑」を「まだできない」から外した）、道具の一覧、技の API の説明、目標ボードの表示
- やっていないこと（§6 のまま）: 水を運ぶ、骨粉、動物を増やす、収穫してまき直すのを候補モードで自動にする

## 追記: 畑の作物を収穫する、取れる物を見せる（2026-09-27）

ユーザー:「畑に生えている小麦を認識できていない。環境情報を渡すときにブロックだけじゃなくアイテムの情報も渡して」（取れる物を添える、収穫したら植え直す、を選んだ）。ログ（14:04〜14:07）: `have(wheat, 4)` で `how_to_get(wheat)` が「no way to get wheat」、家から 232 m 離れていて `find_blocks` も見つけられず、視聴者に「家の前に畑がある」と言われるまで気づかなかった。
- 原因: 作物は掘って取れる物の表（`knowledge.mjs` の `NATURAL_BLOCKS`）になく、記憶（`REMEMBERED_BLOCK`）にもなく、家のまわりの畑は `farmed` の目標のときしか数えていなかった
- 作物（wheat / carrots / potatoes / beetroots）を取れる元にする。掘る対象は熟したものだけ（`world.mjs` の `digTargets` が `isRipe`）。道具 `dig` は育ち途中を断る
- `dig` で熟した作物を掘ると、まわり 5 m の熟した同じ作物も続けて収穫し、拾ってから種で植え直す（`harvestNearby` / `replant`。結果に収穫と植え直しの数）
- 記憶が作物の場所を覚える（離れていても「go to wheat seen at …」で戻れる）
- 取れる物: `Knowledge.dropsOf(block)`（取れる物がそのブロック自身だけなら空）を、`/observe` の覚えている場所に `gives` として添える（「wheat 12（→ wheat・wheat_seeds、北 230m、…）」）。`find_blocks` の作物には `ripe` と `age`（技が使う配列の形は変えない）
- `/observe` の `farm`（家のまわりの作物ごとの植わっている数と熟した数）を「家のまわりの畑」として出す

## 追記: 家の畑が育ち途中なら遠出しない（2026-09-27）

ユーザー:「畑を畑と認識できない」→「自分の畑を使わず遠くへ行く」。15:46〜15:48 のログ: 家の東の畑（小麦 9 マス、サーバーで確かめた age は 1〜5、熟したもの 0。ブリッジの判定は正しかった）では収穫の候補が出ず、ソルバーが「261 m 先で見た小麦へ行く」だけを出し、Gemini はボートで遠征すると決めた。作物はプレイヤーの近く（読み込まれたチャンク）でしか育たないので、遠出すると家の畑も育たない。
- `homeFarm(bot, state, crop)`: 家のまわりのその作物（植わっている数、熟した数、育ち具合 [最小, 最大]、熟したものの場所）。見えれば `state.memory.farm` に残し（保存される）、家のチャンクが読み込まれていなければ記憶を返す
- ソルバー（`gatherOption`）: 作物が見える範囲になく、家の畑にあるとき、熟したものがあれば「家の畑へ行く」だけ（`go to the home farm (N ripe wheat)`、`goto_memory`）。育ち途中なら遠出も探索も出さず、`growing` の葉で理由（植わっている数、育ち具合、家の近くにいる間だけ育つ、その間は家の近くで別の手順を、骨粉を持っていれば使う）を `blocked` と `impossible`（手順の今の状態の「今は手に入らない」）に出す。家の畑にその作物がなければ今までどおり
- `/observe` の `farm` に育ち具合（`ages`、`mature`、記憶なら `remembered`）。「家のまわりの畑: wheat 9 マス（熟した 0、育ち具合 1〜5/7）」
- 残ること: 道具モードの Gemini が自分で `goto` して遠くへ行くことは止めていない（理由は見えている）
