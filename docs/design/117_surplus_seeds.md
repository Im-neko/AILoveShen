# 117. 余った種は捨てる

2026-10-08、user: 「畑の運用で種が余るようになってきました。種は畑の数*1スタック残してあとは捨てて良いです」

## 1. 起きていたこと
収穫のたびに小麦の種が出る。家のチェストには小麦の種が 300 入り（空き 0/27 の一因。設計書 116）、持ち物にも残る。種は預けるだけで、減らす手がなかった。

## 2. 決めたこと
- 残す数: その作物の設計した畑の数 × 種 1 スタック（64）。持ち物と家のチェストの合計で数える。畑がまだなくても 1 畑分は残す（最初の畑に要る）。
- 対象は種そのもの（`_seeds`: 小麦の種、ビートルートの種）。ニンジンとジャガイモは作物を兼ねる（食べ物）ので、この決まりに入れない。
- 目標が種そのものを集めているとき（`have(wheat_seeds, N)`）は捨てない（`goalKeep`）。

## 3. 作ったもの（`minecraft-bridge/src/seeds.mjs`）
- `seedSurplus`: 種ごとの余り = 持ち物 + チェスト − 残す数。
- 候補（`candidates.mjs` `surplusSeeds`）:
  - 持ち物に余りがあれば、その場で「throw away the surplus wheat_seeds」（`toss`。余りまで）。
  - チェストに余りがあり、家の中にいて持ち物に空きがあれば、「take N surplus wheat_seeds from the chest … to throw away」（`withdraw`）。出せば持ち物の余りになり、次に捨てる。
- `tidy`（今使わない物を預ける）は、余った種を預けない（預けてからまた出して捨てる無駄を避ける）。
- 道具 `toss`: 余った種を item に指定して捨てられる（捨てる数は余りまで）。item なしの「余り全部」にも種を含める。余りがない種は「one stack per farm」と断る。

## 3.1 追記: 捨てた種を拾い直し続けた（2026-10-08 01:45Z 以降、実機）
最初の実装で、「throw away the surplus wheat_seeds」が 01:45Z 以降の 94 手のうち 25 手（約 27%）を占めた。数は 265 → 127 → 126 → 64 と、捨てても持ち物に戻っていた。
- 原因 1: その場で捨てていた（家の中の 3x3、または原木を切る作業場のそば）。足元に落ちた種は、少し待てばサーバーが自動で拾い直す。`isTossed` が止めるのはブリッジの「拾いに行く」候補だけで、歩いて近くを通れば拾ってしまう。
- 原因 2: 持ち物の種を全部余りとして捨てていた（余り = 持ち物 + チェスト − 残す数で、チェストに 300 あると持ち物の種はいくつでも余り）。まく種まで捨て、畑の仕事で出し入れした 1 個ごとにまた捨てる手が出た。
- 直した:
  - 捨てる場所は、街（`inTown`: 家・施設とそのまわり 6 マス）の外で、家から `TOSS_AWAY`(28) マス離れた、立てる地面（`tossSpot`）。ボットに近い方向を選び、そこまで歩いて、街から離れる向きに投げる（`toss` の `pos`・`yaw`）。家の中にいれば、実行の前に家を出る（`needsOutside`）。夜の籠もりでは出さない。地面が読み込まれていなければ候補を出さず、道具は理由つきで断る。
  - 持ち物の種は、残す数までは捨てない（まく種）。捨てるのは超えた分だけ（`seedsToToss`）。
  - チェストに余りがあれば、チェストの種を全部出す（空きスロットで持てる分まで）。出せば持ち物が残す数を超えるので、超えた分を捨てて 1 スタックに収まる（1 周）。
  - 道具 `toss` の item なしは、余った物（土・丸石など）があればそれをその場で、なければ余った種を街の外で。

## 4. 代償・未対応
- 畑の数は、設計した畑（`facilities`）の数。家の畑（`home_farm`: 前からある畑）は数えない。
- 捨てた種は、その近く（16 m、5 分）では拾い直さない（捨てた物と同じ扱い。`noteTossed`）。捨てた場所は街の外なので、通りがからなければ拾い直さない。捨てに行く往復は歩く時間がかかる（1 周で片道 28 m 前後）。
- 外のチェストの種は数えない（家のチェストだけ）。
- 畑を増やしたとき、捨てた分を取り戻す手はない（収穫で種はすぐ出る）。
