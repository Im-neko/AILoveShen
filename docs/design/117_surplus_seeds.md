# 117. 余った種は捨てる

2026-10-08、user: 「畑の運用で種が余るようになってきました。種は畑の数*1スタック残してあとは捨てて良いです」

## 1. 起きていたこと
収穫のたびに小麦の種が出る。家のチェストには小麦の種が 300 入り（空き 0/27 の一因。設計書 116）、持ち物にも残る。種は預けるだけで、減らす手がなかった。

## 2. 決めたこと
- 残す数: その作物の設計した畑の数 × 種 1 スタック（64）。持ち物と家のチェストの合計で数える。畑がまだなくても 1 畑分は残す（最初の畑に要る）。
- 対象は種そのもの（`_seeds`: 小麦の種、ビートルートの種）。ニンジンとジャガイモは作物を兼ねる（食べ物）ので、この決まりに入れない。
- 目標が種そのものを集めているとき（`have(wheat_seeds, N)`）は捨てない（`goalKeep`）。

## 3. 作ったもの（`minecraft-bridge/src/seeds.mjs`）
- `seedSurplus`: 種ごとの余り = 持ち物 + チェスト − 残す数。
- 候補（`candidates.mjs` `surplusSeeds`）:
  - 持ち物に余りがあれば、その場で「throw away the surplus wheat_seeds」（`toss`。余りまで）。
  - チェストに余りがあり、家の中にいて持ち物に空きがあれば、「take N surplus wheat_seeds from the chest … to throw away」（`withdraw`）。出せば持ち物の余りになり、次に捨てる。
- `tidy`（今使わない物を預ける）は、余った種を預けない（預けてからまた出して捨てる無駄を避ける）。
- 道具 `toss`: 余った種を item に指定して捨てられる（捨てる数は余りまで）。item なしの「余り全部」にも種を含める。余りがない種は「one stack per farm」と断る。

## 4. 代償・未対応
- 畑の数は、設計した畑（`facilities`）の数。家の畑（`home_farm`: 前からある畑）は数えない。
- 捨てた種は、その近く（16 m、5 分）では拾い直さない（捨てた物と同じ扱い。`noteTossed`）。それ以降に近くで拾うと、また余りになり、捨てる。
- 外のチェストの種は数えない（家のチェストだけ）。
- 畑を増やしたとき、捨てた分を取り戻す手はない（収穫で種はすぐ出る）。

## 5. テスト
`test/seeds.test.mjs`（6 件）: 残す数、持ち物とチェストの合計、種を集める目標では捨てない、候補（家の中と外）、`tidy` が余りを預けない、道具 `toss`。変異 8 つ（畑の数、合計、目標の除外、ニンジンを数える、引き算、預ける、外でも出す、道具の上限）が落ちることを確かめた。
