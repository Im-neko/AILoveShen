## 3. 進め方の方針（2026-09-24 決定）

配信の前に、テストプレイで街づくり・探索・エンダードラゴン討伐まで進め、その過程で見つかる実装の不具合（C: ブリッジのバグや前提の誤り）を潰す。テストプレイで Gemini が蓄えた経験（A: 戦術の調整、B: 戦い方の組み換え）は、配信開始前にリセットする。

失敗の種類ごとに、誰が直すかを分ける:

| 種類 | 例 | 直し方 |
|------|----|------|
| A. 戦術の調整 | ウサギは速すぎる、クリーパーがドアの前にいる朝は出ない | 配信中に Gemini が教訓として覚える（M1.5） |
| B. 戦い方の組み換え | 剣を作ってから戦う、夜の前に帰る | Gemini が Goal の選び方で吸収する。足りない行動はコードで足す |
| C. 実装の不具合 | `pathfinder.stop()` の仕様、失敗を成功と返す、Paper の連打制限 | テストプレイ・配信のログから、配信外でコードを直す |

注意: C は「潰し切る」ものではない。行動を足すたびに新しい C が生まれるので、各マイルストーンで実行して直す。コードに入れた対策（敵を避ける経路など）はリセットの対象外。

## 4. マイルストーン

各マイルストーンは「自律実行で確認できたら完了」とする。確認はワールドの状態（RCON）とサーバーログで行い、アクションの戻り値には頼らない。

### M1 生存基盤（第1段階）

夜と敵がいる既定の条件で、家を建て、夜を越し、朝に作業へ戻れる。

- **反射**（ブリッジ）: 近くの敵を常時監視し、アクションの実行中でもステップの合間でも、先に逃げるか戦う。判断を待たないコード側の反射
- **逃走の修正**: 追ってくる敵から実際に離れられること（`GoalAwayFrom`）
- **木の剣**: クラフトして持つ。反射で戦うのは剣があるときだけ
- **夜を越す**: 夕方になったら家に戻り、ドアを閉めてこもり、朝に出る。ドアの開け閉めは明示的に行う（pathfinder はドアを扱わない）
- **拠点の永続化**: 建築計画と家（ドアの位置、中のマス）をブリッジがファイルに保存し、再起動しても引き継ぐ
- **食料**: 動物を狩って食べる
- **Goal の選び直しを時間帯で起こす**: 夕方・朝の切り替わりで LLM に Goal を選び直させる

**完了条件**: `time set 1000` から一晩（実時間で約25分以上）通して実行し、サーバーログに死亡がなく、夜の間は家の中でドアが閉まっていて（RCON で確認）、朝に作業を再開している。

### M2 チャットへの返答（第1段階）

Twitch のコメントに、shen がゲームの状況を踏まえて声で返す。ゲームのループは止めない。

- **受信**: Twitch EventSub WebSocket（`channel.chat.message`）。認証はデバイスコード方式の OAuth（Public クライアント、`user:read:chat`）。トークンは pass に保存し、更新時に書き換える
- **返答**: 既存の `GenerateResponseUseCase` に、今の Goal・直近の行動・建築の進み具合を渡す（渡さないとゲームの状況を作り話で答える）
- **出力**: shen の声（Style-Bert-VITS2）。コメント自体は棒読みちゃんが読む。返答は受信から約4.5秒後に始まるので、短いコメントなら棒読みちゃんの後になる
- **安全**: コメントは返答文の生成にだけ使い、Goal や行動には影響させない（プロンプトインジェクション対策）。返答の最小間隔を置く
- **並行実行**: ゲームのループと返答は同時に動く。身の安全はブリッジの反射が担う

**完了条件**: 自律実行中に ailoveshen のチャンネルへコメントすると、ゲームのループを止めずに、shen がその時の状況（Goal や直前の行動）に合った内容を声で返す。

### M1.5 経験の蓄積（教訓メモリ）

- Gemini がアクションの失敗・中断・死亡の理由から、短い教訓を書いて保存し、以後の Goal 判断のプロンプトに入れる
- 失敗を構造化ログに残し、配信（テストプレイ）後にコードの修正（C）へ回す
- 配信開始前に教訓をリセットできるようにする

### F エージェントのライフサイクル（M3 の前）

Gemini（方針）/ Jev（遂行）/ 反射の分担と、短期目標の発行・検証・終了・再計画の流れを確立する。プロジェクト全体の枠組みなので、設計は `10_agent_lifecycle.md` に置く。M3 以降は Goal と行動が一気に増えるので、その前に Minecraft に適用する。

2026-09-25 決定: M2 の残り（Twitch のアプリ登録待ち）とスクショ（vision）より先に進める。複合アクション（`craft_bed`、`hunt_sheep` など）を配信外で毎回手書きするのをやめ、根源的な行動の組み合わせで実現する。最初に、Jev が引数付きの候補から正しく選べるかをスパイクで測る。
