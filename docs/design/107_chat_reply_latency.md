# 107. コメントへの返事が 8 分遅れた原因: 家がないのに建物を設計していた

2026-10-07、user: 「全然コメントしてないタイミングでコメントに反応してるかも」「コメントは割り込みで反応してあげられるようにしたい。反応がなかなかもらえないと悲しいから」

## 1. 起きていたこと（`zmx history stream`、`logs/generations`、`logs/promises`）

コメントが届いてから返事までの時間は、ふだん 5〜60 秒。20:41 から 3 回、400〜630 秒（7〜10 分）になった。

| コメント（JST） | 返事 | 遅れ |
|---|---|---|
| 20:41:57 ねこかも「家建てれるとこま…」 | 20:50:22 | 505 秒 |
| 20:46:08 / 20:50:12 | 20:56:40 / 20:56:53 | 632 / 401 秒 |
| 20:56:32 / 20:56:45 / 20:57:43 / 20:58:22 | 21:06:20〜21:06:59 | 517〜590 秒 |

コメントした人から見れば、コメントのない時に返事が来る。遅れた返事が「家を作る」と約束すると、その約束で夜越し（`through_night`）が切られた（21:06）。

## 2. 原因

返事（`GenerateResponseUseCase`）が大目標を受けるとき、`ObjectiveKeeper.accept` → `_design_builds` → `BuildDesigner.design` が、その場で Gemini に建物（`build_design`、画像つき、1 回 40〜200 秒）を設計させる。返事は設計が終わるまで話されず、返事は 1 件ずつ順に作る（`ChatResponder`）ので、あとのコメントもすべて待つ。

`build_design` が 3 回とも、ブリッジの `build house rejected: there is no home yet: build the house first` で断られた（12:00〜12:06Z: 141 + 208 + 37 + 86 秒 ≒ 8 分。20:45、20:46 も同じ）。名前付きの建物は家の隣に登録されるので、家がないうちは、どんな設計でも断られる。プロンプトにも「家はまだない」と書かれていたが、設計はそのまま呼ばれていた。

## 3. 直したこと
`BuildDesigner.design`: 家がなければ、設計を呼ぶ前に `GoalRejectedError("there is no home yet: build the house first")` で断る。返事はその理由を受けて作り直す（頼みは受けられなかった、と言わせる）ので、数秒で終わる。

## 4. 直していないこと（user の判断が要る）
「割り込みで反応する」は、まだ満たしていない。家があっても、設計は 1 回 40〜200 秒かかり、その間、あとのコメントは待つ。案:
1. コメントが届いたら、すぐ短い相づち（「見てるよ」など。LLM を使わない決まった一言）を話し、中身の返事は順に作る
2. 返事は先に話し、建物の設計は、返事のあと裏で行う（設計が断られたら、あとで言い直す）
3. 返事を 1 件ずつでなく、同時に作る（会話の順が崩れる恐れ）

## 5. テスト
`tests/unit/application/test_builds.py`: 家がなければ、LLM を呼ばずに断る。外すと落ちることを確かめた。
