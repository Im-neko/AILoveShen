# 146. 暗い竪穴で松明を置く・穴から出る行動は考え直しで止めない

2026-10-10、user: 「暗闇で松明置かなくなっちゃったかも」「このいま暗いのに松明を置いていないのと、家に帰れない状況をまずはどうにかしたい」
（`logs/bridge.log` 05:19〜05:38Z）

## 1. 起きていたこと
- 05:21Z 鉄のツルハシが壊れ（探索中）、05:29Z 石のツルハシも壊れた（`go_home` の途中）。夜越しの穴（283,69,-539）から `go_home` が洞窟づたいに西へ下り、(232,47,-508) で `No path to the goal!`
- そこから岩の中の竪穴を、素手と足場の丸石で 14:31〜14:37（JST）かけて y=47 → 約 70 まで登った。この間 `needs` は「dark here」のまま、松明 11 本を持っていたが 1 本も置かなかった
- 05:31:58Z、`climb_out` が 71 秒登ったところで `rethink: you told ディレクター you would do "区画間の道を整備して街をつなぐ" now …` に止められた。穴の途中で決め直し、`craft stone_pickaxe` が 18 m 下の作業台へ歩こうとして `No path to the goal!` を 4 回繰り返した

## 2. 原因
- **松明**: `[trail]`（`trail.mjs`）は行動の途中で置くが、`TRAIL_VERBS` が歩く・掘る行動だけで、穴を登る行動（`leave_burrow` / `climb_out` / `dig_out` / `surface`）は入っていなかった。直近 2 時間の記録では、歩く・掘る間は 66 本置いていて（失敗 4 本はどれも持ち替えの競合）、置かなくなったわけではない。置かれなかったのは竪穴を登る間
- **考え直しが出る行動を切る**: 視聴者・配信者の頼み（`when=now`）は `rethink:` の理由で実行中の行動を止める（`play.py` `_cut_on_rethink`）。夜越しの間だけ待たせる（`defers_rethink`）。穴から出る途中の行動は待たせていなかった
- **作業台が遠い**: `craft` は見える範囲の作業台へ歩く。届かないとき、作業台を持っていれば置くよう案内するが、持っていなければ `No path to the goal!` だけだった

## 3. 直したこと
- `TRAIL_VERBS` に `leave_burrow` / `climb_out` / `dig_out` / `surface` を足した。竪穴を登ると、足場を置くとき足元の松明は壊される（`home.mjs` `jumpAndPlace`）ので、置いた所から `TORCH_MIN_GAP`（5 m）以内では置き直さない（暗いまま 1 段ごとに置き直して使い切らない）。歩く間は、もともと光源から 8 m 以上離れた所にだけ置くので変わらない
- `ESCAPE_VERBS`（`leave_burrow` / `climb_out` / `dig_out` / `surface` / `reach_land`）の間は、`rethink:` の中断を断る（`runner.mjs` `abortCurrent`）。依頼は消えず、出たあとの切れ目で効く。ほかの理由（見張り、体力、敵）では今までどおり止まる
- `craft` が作業台へ届かないとき、板が 4 枚あれば「板 4 枚で作業台を作って、そばに置いて作り直す」と案内する

## 4. 直していないこと
- 石のツルハシが折れる前に次を持つこと（鉄のツルハシが探索中に壊れ、石のツルハシが `go_home` の途中で壊れて、素手で竪穴を登った）。設計書 101 の予備は採掘場の中だけ
- `go_home` が洞窟づたいに下る道を選ぶこと（設計書 145 で採掘場の階段と、地下から地上への高さを含む目標は入れたが、採掘場でない洞窟は経路探しの費用のまま）
- `leave_burrow` が 1 回に登るのは 3 マス（`BURROW_DEPTH`）で、深い竪穴は何度も決め直しになる。水や溶岩の確認がない行動なので、上限は上げていない
