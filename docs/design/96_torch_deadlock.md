# 96. 松明を失うと、石が「手立てなし」になって何も進まない

2026-10-07、user: 「なんか全然進まないなあ。これぜんぶ敵が家の近くにいるせい？」→「なんか失敗してそう」→ 案 A。

## 1. 起きていたこと

02:42〜（Z）、昼なのに実行した手が 0 件（`logs/steps`、`logs/generations`、`/observe`）。

- LLM は `have(cobblestone, 3)` を 41 回選び、ブリッジは受け付けるが `dead_end: no way to get cobblestone / raw_iron` を返す。実行できる候補は `equip wooden_sword` だけ
- 部品を `/check` で見ると、原木・板材・木のツルハシは作れる。`stone` / `coal` / `charcoal` / `torch` はすべて「no way to get」
- 3 回死んで（10:27〜10:31 JST）松明と持ち物を失っていた。それまでは松明を持っていたので表に出なかった

## 2. 原因（`solver.mjs` `gatherOption`）

家があるとき、石・鉱石は採掘場（地下の手: `go_mine` / `dig_mine` / `make_mine` / `dig_down`）からしか取らない。地下の手は「松明 8 本を先に」と要求する（2026-10-01、暗い所の湧きで撃たれ続けた対策）。

- 松明 ← 石炭 ← 地下の石炭鉱石 ← 地下へ下りる手 ← 松明（輪）
- 松明 ← 木炭 ← かまど ← 丸石 ← 地下 ← 松明（輪）

`path` に同じ品が入ると「手立てなし」になる解決器の作りで、どちらの道も塞がり、松明がなければ石も石炭も一生手に入らない。

## 3. 直したこと

地下の手が松明を要求するとき、松明が（輪で）手に入らない（cost が IMPOSSIBLE）なら、松明の要求を外す。松明の石炭を取る手は松明なしで下り、石炭ができたら松明を作り、その後に石へ行く（`松明 8 本 ← 石炭 2 ← 採掘場`）。松明が手に入るなら今までどおり先に要求する。剣の要求は変えない（木で作れるので輪にならない）。

- 台帳は試しの複製で評価し、手に入るときだけ反映する（手に入らない評価で材料を使い切らない）
- テスト: `solver.test.mjs` に 2 件（松明も石炭もない: 輪にならず石炭が先、松明を持っていれば従来どおり）。直す前は 1 件目が `no way to get cobblestone` で落ちる
