# 101. 採掘場の底で道具が壊れても出られるようにする

2026-10-07、user: 「全然進んでないんじゃない？」→「直して良いです。」
（`logs/steps` 05:32〜06:10Z、`logs/bridge.log`）

## 1. 起きていたこと

採掘場 mine_2 を y=16 まで掘り下げる間に、石のツルハシと木のツルハシが 2 本とも壊れた（05:32Z）。その後、y=63（家の床 69 まで 6 ブロック）の縦穴で約 40 分、何もできないまま閉じ込められた。持ち物は丸石 74、板材 3、棒 5、作業台 1。出る道が 3 つとも塞がっていた。

| 出る道 | 塞いでいた規則 |
|---|---|
| 岩を掘る | ツルハシがない。素手で掘る例外はあるが、岩が「地表に近い」と断られた |
| ツルハシを作る | 作業台は地下に置かない（設計書 77） |
| 土・丸石を積む | 掘れないと積む足場が足りない |

4 つ直したあとの再起動で、まだ出られないと分かった。縦穴は 1×1×2 で、屋根は岩 3 層 + 土 2 層（岩の厚み 6）。`isUnderground`（厚み 8 以上）が偽なので、素手で岩を掘る例外（`checkHarvestable`、「地下で閉じた所」の条件）が効かず、`leave_burrow` が屋根を掘れなかった。作業台も、置く空きセルがない（まわりは岩）。

もう 1 点: 手に松明を持ったまま掘っていた（`torchInMine` が松明を持ち、置いたあとに戻さない）。松明は掘る道具にならず、素手と同じ遅さだった。

## 2. 原因

どの規則も、それ単体では筋が通っていた（暗い地下に作業台を置かない、地表に近い岩を掘らない）。組み合わさると「道具が壊れたら出られない」輪になった。「道具が壊れる」場合を誰も数えず、採掘場へ下りるときに予備を持たせていなかった。

「地表に近い」の判定（`shallowStone`）は、頭の上の岩の厚みを数える。自分で掘った縦穴（採掘場の階段）の下は、頭の上が空気なので厚みが薄く見え、地下 28 ブロックの岩も浅いと判定された。

## 3. 直したこと

| 件 | 直し | 場所 |
|---|---|---|
| 作業台 | 閉じた地下で、ツルハシを 1 本も持っていないときは、作業台を置いてよい（かまどは今までどおり家の中だけ） | `primitives.mjs` `stationRefusal` |
| 地表に近い判定 | 家の床より `SURFACE_DEPTH` 以上下の岩は、頭の上が空気でも深いとする | `mining.mjs` `shallowStone` |
| 予備のツルハシ | 採掘場へ下りる前に、掘る道具のほかに木のツルハシを 1 本持つ（作れるときだけ。作れなければ要求しない） | `solver.mjs` `gatherOption` |
| 素手で岩を掘る例外 | 「地下で閉じた所」から「閉じた所（家の中を除く）」に広げた。浅い縦穴でも、閉じ込められたら素手で屋根を掘って出られる | `primitives.mjs` `checkHarvestable` |
| 松明のあと | 置いたあとは、持っていた物に持ち替える | `primitives.mjs` `torchInMine` |

## 4. テスト

- `safe_work.test.mjs`: 閉じた縦穴では、ツルハシがなければ作業台を置ける。かまどは断る。ツルハシがあれば作業台も断る
- `mining.test.mjs`: 自分で掘った縦穴の下の深い岩は掘れる。浅いままは浅い
- `solver.test.mjs`: 予備がなければ木のツルハシを作る手が先に出て、採掘場へはまだ下りない。あれば下りる
- `safe_work.test.mjs`: 浅い縦穴でも素手で掘れる。開けた所と家の中は断る
- `mine.test.mjs`: 松明を置いたあとツルハシに持ち替える。既存の solver / mining のテストの持ち物に、木のツルハシを足した

どれも、直しを外すと落ちる。
