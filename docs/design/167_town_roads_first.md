# 167. 道と街を、全体を設計してから作る

2026-10-11、user: 「道や街も全体的な設計をしてから作るようにして欲しいです」「そして再設計した時、計画に合わない既存の建築は更地に出来るようにしたいです」
user の答え: 設計 = **コードが道の骨格、LLM が区画の用途**／道 = **シャベルで土の道（dirt_path）**／計画に合わない建築 = **一覧を出して、LLM が選んで更地にする**。

## 1. 事実（調査）
- 街の理想図（設計書 47 §6）は、12 x 12 区画（1 区画 8 ブロック）に LLM が用途を割り当てる図。用途に `road` と `plaza` はあるが、ただのラベル: 道がつながっているか、施設に面しているかを誰も確かめず、道を敷く手もない（プロンプトは「道は要るなら施設をつなぐ細い列」とだけ言う）
- 今ある施設・家・水・溶岩の区画は固定で、LLM が動かせない。だから、再設計しても「今ある建築が計画に合わない」ことはなく、更地にする手も要らなかった（固定のまま計画に入る）。user が求めているのは、計画のほうを優先して、合わない既存の建築を片付けられること
- 更地にする手: `level {demolish}`（座標指定）、`build_next {name, reset}`（名前付きの建物）、`clear_old_home`（前の家。設計書 166）。計画に合わないと判定して一覧にする所はない

## 2. 段階
1. **道の骨格**（この設計書の §3、実装済み）: コードが道の区画を決める。LLM は道に面した区画に用途を割り当てる
2. **道を敷く**（§4）: 道の区画の中を通る土の道を、シャベルで敷く手
3. **計画に合わない既存の建築を更地にする**（§5）

## 3. 道の骨格（実装済み）
`town_roads.py` の `plan_roads`（決まりきった手順。LLM は使わない）:
1. 家の区画から、東西南北に最大 4 区画の大通りを延ばす。固定の区画（施設・水・溶岩）に当たったら止まる。家がまだなければ、真ん中に近い空き区画から
2. 道に面していない施設（固定の区画）を、家に近い順に、空き区画だけを通る最短の道で道へつなぐ（道まで 8 区画を超えるなら諦める）
3. 前の理想図の道は、まだ空いていれば残す（描き直しで道が動かない）
4. 道は最大 28 区画（街の約 2 割）

`town_map.py`: `draw_base`（施設・地形の固定に、道の骨格を足した区画）。`apply_areas` は、LLM が割り当てた用途のうち、**道に面した区画を 1 つも含まないもの**を差し戻す（採掘場は石のある所に作るので例外）。`road` は LLM が割り当てられる用途から外した。プロンプトの地図に `=`（道、固定）を足し、決まりを「道はコードが決めてある。施設は道に面した区画に置く」にした。

限界: 道は区画（8 ブロック）の単位で、実際に敷く細い道（3 ブロック幅）は §4 で、道の区画の中央を通るようにする。地形（水・崖）で区画が使えない所は、道が回り込まず途切れる（その先の施設は、近い道につなぐか、つなげなければ道に面さないと差し戻される）。
