調べた（`data/logs/ailoveshen-dev.log`、`GET /facilities`、`data/mission.json`）:

- 街の計画は、畑（`facility(wheat_farm_1)`）・植林場（`oak_grove_1`）・鉄のつるはしが Stage 3。Stage 2（松明 32 本・明かり・食料の備蓄 16）が済むまで始まらない。Stage 2 は 8 時間済まず、食料の備蓄に要るのは畑そのもの。基盤が、基盤の成果を待つ形になっていた
- 視聴者の助言から作った大目標「食料の安定供給: 小麦畑を作る」は、条件が `have(wheat_seeds, 4)` と `have(hoe, 1)` だけで、木のクワを作った時点で達成になった（畑は 1 マスも耕されていない）
- 「Neo-Shenburgに引っ越す」が 02:25 から 09:30 まで 10 回以上、足されては達成になった（1 回に 3〜14 分、先頭に入り、計画の LLM 呼び出しも使う）。原因は `build.mjs` の `isPlaced` が、読み込まれていないチャンクのブロックを「置いていない」と数えること。家から離れると `built()` が 0/88 に見え、`town._move` が引っ越しを足し、近くへ戻ると達成になった

## 2. 決めたこと

**(1) 離れても家は建ったまま**（`build.mjs`）: `BuildPlan.seen` = 置いてあると最後に見たブロックの世界座標。`isPlaced` は、読み込まれていれば見たとおりに答えて `seen` を更新し、読み込まれていなければ `seen` で答える（一度も見ていなければ未達）。`toJSON` / `fromJSON` で保存する。近くに戻って壊れていれば、見たとおりに未完成へ戻る。家と名前付きの建物のすべてに効く。

**(2) 基盤は街の段階を待たない**（`objectives.py` `ObjectiveKeeper._ensure_infrastructure`、コードが決める）: 小目標の切れ目の判定（`judge`）の最後で、次を満たすと、足りない種類（畑 `farm`、植林場 `tree_farm`）の大目標を先頭に足す。

- 街と場所が決まっていて、引っ越しの準備が残っていない（`plan.town`、`preparing_town`）
- 家が建っていて（`house_complete`）、家から 64 m 以内（区画が読み込まれている。設計は家の近くで）
- その種類の施設がまだない（`GET /facilities` の `kind`。建設中でも数える）。同じ種類らしい名前（設計前なら名前の語）の施設が、すでに大目標にある場合も足さない
- 施設の大目標が 2 つ未満（`INFRASTRUCTURE_MAX_PENDING`）。リストがいっぱいなら空きを待つ
- 調べるのは 180 秒に 1 回。設計に失敗した施設は 3 回まで（`INFRASTRUCTURE_TRIES`）

条件は `facility(<名前>)` だけ。名前は街の段階がすでに決めたもの（`wheat_farm_1` など。同じ施設になるので Stage 3 とも重なる）、なければ `wheat_farm_1` / `oak_grove_1`。設計は既存の `FacilityDesigner`（`purpose=facility_design`）。採石場（採掘場）は足さない: 掘る場所はブリッジが自分で設計する（設計書 68）。

**(3) 偽の完了を断る**（`plan_lint.fake_infrastructure`）: 題名に「畑・農場・農園・植林・果樹園」（farm / grove / orchard / plantation）とあるのに、条件に `facility` / `farmed` / `planted` がない大目標の提案（視聴者の頼みと助言、配信者自身の編集）は、`facility(<新しい名前>)` を入れるよう理由を添えて差し戻す。中目標（`job`）には適用しない。「採石」は題名に使うのが普通なので対象外。

## 3. 実機で見ること

- 家が建ったあと、`[objective+] 小麦畑を作る` と `植林場を作る` が先頭に出ること、`GET /facilities` に `kind: farm` / `tree_farm` が増えること
- 引っ越しの大目標が足され続けないこと（`[objective+] … 引っ越す` が 1 回きり）
- 畑の施設の小目標（till / sow / plant、水、種）が、食料の危機（夜、空腹）の中でも進むか。畑の手順は設計書 33 / 47（実機では未確認）
- 設計が続けて失敗していないか（`生活の基盤 … を設計できない`）
