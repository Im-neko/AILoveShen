# 194. 技の失敗: 直すか、やり直すかを選べる材料

2026-10-18。ユーザー: 「技が失敗したら、フィードバックして、修正するかリトライするか判断できるようにしたい」。

## 前の案内の問題
失敗のたびに「原因を探して、すぐ直せ。同じコードを動かすな」と一方向に言っていた。
- やり直せば通る失敗（敵が近くにいた、直前に状況が変わった）も、書き直しに向かった。
- 逆に、直さずに同じ技を動かし続けても止める材料がなかった（2026-10-18: 止まった技を 10 分 x 2 回）。

## 入れたもの（`skill_feedback.py` の `SkillHistory`）
失敗の結果の末尾に、決めつけず、材料を並べた短い案内を付ける（通常の `tools` と raw の両方）:
- この技の成績: 何回中何回成功、最後の成功から何回前（成功がなければ「まだ成功なし」）。動かさなかった断り（refused）は数えない。
  保存した技も保存しない試しも同じ名前で通して数える（直しながら試す流れを見る）。
- 今回の失敗の種類と目安:
  - 例外（error）: コードの不具合。直す。
  - 時間の上限（stopped で理由が時間・待ちなしの繰り返し）: 直す（待ちに上限を付け、t.fail で降りる）。
  - 外から止められた（stopped。反射・見張り）: コードの欠陥ではない。原因（近くの敵）に対処して、そのままやり直す。
  - 技が自分で降りた（fail）: log と現場（設計書 193）を読む。状況（敵、足りない物、空きマスがない）なら、状況か引数を変えてやり直す。
    間違って降りたなら直す。
  - 終わったが条件を満たさない（done）: 仕事が済んでいないなら直す。済んでいて expects が違うなら expects を直す。
- 繰り返しの目安: 同じ理由が 2 回以上続けば「変えること」、3 回動かして一度も成功しなければ「先に直す」、
  半分以上成功していて今回が初めての失敗なら「状況かもしれない」。

通常のプレイでは、見張りが止めた失敗（stopped）には案内を付けない（技の欠陥ではないので、前と同じ）。数には入れる。
前の固定文（`SKILL_FAILED_NEXT`、`TRY_FAILED_NEXT`）は消した。

## 決めていないこと / 確認していないこと
- 案内を受けて LLM が「やり直し」と「直す」を使い分けるかは、実機で未確認（ベンチ raw_free で見る: 同じ理由の連続回数、直さずに続けた回数）。
- 目安の数（3 回、半分）は仮。

## 書き直しで成績を数え直す（2026-10-18 追記）
raw の 5 回目で、`craft_planks_from_logs` が書き直しても名前で数えられ続け、v3 の失敗に「3 of 15 runs succeeded」と出た（v1・v2 の分を含む）。
成績は今のコードの分だけにする: 技を書いた・書き直したとき（`write_skill`、`try_skill`）に成績（実行数・成功数・最後の成功からの数）を 0 に戻す
（`SkillHistory.rewritten`）。同じ理由で続けて失敗した回数は残す（書き直しても同じ理由、が見せたい事実）。実行中の 5 回目には入っていない（再起動で入る）。
観察: その「3 of 15」を見ても LLM は直さず同じ技を 5 回動かした（未解決。案内の強さか、案内の置き場所か、次の実験で見る）。

## 動かせなかった（409、404）は、コードの失敗ではない（2026-10-18 追記）
raw の 5 回目（17:47〜18:06）で、LLM が 5 分近く「another action is running」と「there is no skill named …」に当たり続けた。
- 409 は、反射（近くの敵への対処。ゾンビとクモに追われた 2 分間）か、動いている行動・技のとき。理由を分けず "another action is running" にしていたので、
  LLM は反射が動いていることを知らず、「コードが例外を出した。直せ」という案内（`ended: error`）を受けて、確認用の技を書き続けた。
- 404 は、`try_skill` で試しただけの名前（保存していない）を `run_skill` で呼んだとき。これも「コードの失敗」として案内していた。
直した: ブリッジの 409 に `why`（reflex / skill / action）を添え、Python のクライアントは 409 と 404 を **断り（`refused`）** として返す
（動かしていないので成績にも数えず、直す案内も付けない）。理由の文: 「not started: the reflex against a nearby enemy is running; skills are refused until it ends
(it ends by itself: wait, or deal with the enemy)」、「there is no skill named X. A try_skill trial is not saved: save it with write_skill (the same name), or try it again with try_skill」。
保存前の名前を選択肢から隠す案（enum）は、まだ入れていない（案内の文だけ直した）。
