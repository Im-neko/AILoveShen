# 133. 仮の小屋を、壁の高さ 2 と土の壁でもっと早く建てる

2026-10-09、user: 「直してほしいです。また、仮設小屋は土の小屋も採用可能にしてほしいです」（設計書 132 の判断待ち 3 つへの返事と追加）。

## 1. 決めたこと
仮の小屋（最初の家。設計書 109）の材料を減らす。5x5、柱なしは 109 のまま。

| | 109 | 133 |
|---|---|---|
| 壁の高さ | 3 | **2**（ドアと同じ高さ。屋根の下は 2 マス） |
| 壁と屋根の材料 | 板材 | **板材か土**（`wall_material`。LLM が選ぶ。プロンプトは dirt を勧める） |
| 必要ブロック | 板材 71 + ドア | 土 55 + ドア、または板材 55 + ドア |

- `HouseBlueprint`: `wall_material`（`BlockKind.PLANKS` / `DIRT`、既定は板材）、`MIN_HUT_WALL_HEIGHT = 2`。壁・屋根の材料に使う。柱は `corner_pillars` のとき原木のまま
- 仮の小屋のスキーマ（`PROVISIONAL_HOUSE_SCHEMA`）は壁の高さを 2 に固定し、`wall_material` を足す。`provisional_design` が壁の高さ 2、柱なしに直す。材料を書かなければ板材
- 引っ越し先の家（LLM が決める家）は今までどおり壁 3〜4、板材だけ。2 の壁や土の壁を書いたら差し戻す（`_check_house`）
- ブリッジへ送る設計に `wall_material` を足した。ブリッジの計画は、ブロックの種類（`dirt` は土か草のブロックで置いたことになる）で動くので、そのまま土の壁を建てる。材料は土として数える（ソルバーが土を集める）
- ブリッジ `home.mjs`: 土の壁（草に変わった壁も）を壁として扱う。出口を掘る・戻すのに使う（壁を掘って出る手が、土の小屋で効かなくなるのを防ぐ）。戻すときの材料は、掘ったブロックの種類（原木・土・板材）から決める

## 2. 見送ったこと
- 「先に斧を作る」: 土の小屋なら原木はドア用の 2 本ほどで、効果が小さい。板材の小屋を選んだ場合の原木 14 本には効くが、ソルバーの変更が要るので入れていない
- 丸石の壁: ツルハシが要り、採るのに時間がかかる

## 3. 注意・未確認
- **壁の高さ 2 は計測していない**（109 は 5x5x3 と 7x7x4 が置くのに失敗しなかったことを確かめた範囲）。ブリッジの計画は高さを `plan.size` から取るので高さ固定の決めつけは見つからなかったが、実機で屋根まで建つか、ベッドや家具が入るか、ドアが付くかは未確認
- 屋根の下が 2 マスなので、ジャンプはできない（1.25 マス）。中での移動は水平だけ
- 土の壁は、隣の草から広がって草のブロックに変わることがある（計画も出口も草のブロックを土として扱う）。見た目が仮でよい前提
- 土を 55 個、素手で掘る（1 個 0.75 秒ほど）。掘った穴は水や溶岩に近い所では危ない（既存の掘る手の決まりが見る）
- LLM が dirt を選ぶとは限らない（プロンプトで勧めるだけ）。選ばせるなら、コードで決める手もある（user の判断）
