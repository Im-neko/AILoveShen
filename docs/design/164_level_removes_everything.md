# 164. 整地は範囲内のブロックを全部除去する

2026-10-11、user: 「整地の時土ブロックしか壊していないように見えます。整地は範囲内のブロックを全て除去してください」。範囲の確認（AskUserQuestion）の答え: 「家・建物・畑・採掘場以外は全部壊す」。

## 1. 今まで
整地（`leveled` / `level`）は、床の高さより上の出っ張りのうち、自然の地形（土・石・砂など。`TERRAIN`）だけを掘り、木、置いた物（板・原木・チェスト・丸石など）が 1 つでもある列は、その列ごと残して「そろえられない」と数えていた。`demolish: true` のときだけ、置いた物・木・家・建物・畑も壊した。

## 2. 変更
- 既定で、床の高さより上のブロックを、種類を問わず全部掘る（壊せないブロックの列と、水・溶岩の列だけは残す）。木も掘る
- 残すもの（`demolish: true` のときだけ壊す）: 家・前の家・建物とそのまわり、植えた木のまわり、畑（耕地）。採掘場、水・溶岩、壊せないブロックは `demolish` でも残す
- 畑の整地（`farmLevel`、畑の柵の輪を含む）だけは今までどおり（自然の地形だけ）。畑の柵や作物を壊さないため（`columnWork` の `loose: false`）
- 説明（`tool_catalog.py`、`goal_vocabulary.py`、`abilities.yaml`）を合わせた

## 3. 注意
- 置いた物にはチェストも含まれる。中身は落ちる（拾う）。整地の範囲に家の外のチェストがあれば壊す
- 家のまわりの整地は、家の床と同じ高さのときだけ（設計書 163）。家を壊さないための前提になっている

## 4. テスト
`test/leveling.test.mjs`（木・置いた物も掘る、家の列は残す、demolish は家も壊す、畑の整地は今までどおり）
