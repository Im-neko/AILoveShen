# 118. 置く先がふさがっていたら、隣を教える

2026-10-08、user: 「チェストを既存のチェストの位置に置こうとして失敗してます。こういときもLLMが判断して隣に置き直すとか出来るようになっててほしいです」

## 1. 起きていたこと
1. 道具 `place` は、置く先がふさがっていると「44,68,-199 is taken by oak_door」とだけ断った。次にどこへ置けるかは書かれず、LLM は座標を当てずっぽうに変えた（2026-10-07 16:39 には 3 回断られた: ドア、y 抜け、板材）。
2. 家の中のセル（43,68,-200 と 45,68,-200）に置く手 `place_at` が、閉じた家の外から「Took to long to decide path to goal!」で 2 回失敗した（2026-10-08 01:47Z）。セルは空気で、下は草。家に入らずに、家の中のセルへの経路を探していた。失敗は台帳に残り、`place` は「tried before and will not work」で同じ場所を断った。

## 2. 直したこと
- `place` が断るとき（ふさがっている、置く面を借りる隣がない）、隣の置ける所を添える: 「Free spots next to it: x,y,z; … (place there instead)」。同じ高さで 2 マス以内、空いていて、面を借りる隣があり、足元でなく、置いてよい所（家の部屋の中、仮設、保護されていない所）、最大 4 つ、近い順（`tools.mjs` `nearbySpots`）。LLM はこれを見て、隣に置き直す。添えた所は、そのまま `place` に通る。
- `place_at`（`primitives.mjs`）は、置くセルが家の部屋にあり、ボットが家の外にいるときは、先に家に入る（`enterHome`: ドアを開けて歩いて入る）。家の外のセルには、家に入らない。

## 3. 未対応
- 経路の時間切れ（`Took to long`）を「同じことをしても同じ」と台帳が見ること（設計書 114 にも書いた）。家に入る修正で起きにくくなるが、別の場所の経路の時間切れは、台帳に残る。
- 候補（`do_suggestion`）の `place_at` が失敗したときの代わりの候補は、今までどおり、ブリッジが次の候補を出す。

## 4. テスト
`test/place-neighbour.test.mjs`（4 件）: 既存のチェストの位置に置こうとすると隣の候補が付き、その候補は通る、家の中の置いてよい所だけ、足元と置く面のない所は外す、`place_at` は家の中のセルなら先に家に入る（外のセルなら入らない）。変異 6 つが落ちることを確かめた。
