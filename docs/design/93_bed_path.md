## 1. 起きていたこと

配信は動いていたが、22:48Z（07:48 JST）から 1 時間以上、同じ所で足踏みしていた。家の中（ベッドの上）にいて、家の外（5 m、2.6 m 下）にピリジャーがいる。昼で、小目標は `cleared()`（ドアの前の敵を倒す）。候補の `attack pillager #…`（素手でも出る）も、壁を掘って出る `exit through the … wall` も、`goto` も、すべて 0 秒で `No path to the goal!` になった。LLM は出られないまま `collect_wood_safely`、`_v2`、`collect_wood_from_inside` と技を書いては失敗させ続けた。

## 2. 原因（再現して確かめた）

ボットの位置は (73.5, 69.6, -206.1)、`inspect` で足元は `white_bed`（part=foot）。ベッドの上に立っていた（22:47:30 の `sleep` が「近くにモンスターがいる」で失敗し、ベッドの上に乗ったまま）。

家の中の経路は、`primitives.mjs` の `configureMovements` の「建築中の建物の上は歩かない」（`state.plan` の敷地の上で `p.y > o.y + 1` のセルに 101 を足す）で止まる。pathfinder は 100 以上を「通れない」にする。ベッドの上に立つと、足は `o.y + 1`（70）、頭のセルは 71 で、この規則に掛かる。出発点のどの手も頭のセルが 101 になり、隣のセルが 1 つも出ない。家の中のどこへも、家のドア（コードが出入りする）へも、経路が立たない。壁の掘り出しも攻撃も、最初に家の中を歩く（`walkTo(home.inside)`）ので同じ所で落ちる。

再現: 本物の `Movements` と `configureMovements` と家の形（床 y68、壁の輪、ベッド）で、ベッドの上の開始点から `getPathFromTo` を呼ぶと `noPath`、床の上なら `success`。`exclusionAreasStep` を空にすると `success`。

## 3. 直したこと

`configureMovements` の規則を、壁の輪の内側（部屋）の、足が 1 段高い所（ベッド・チェスト・作業台の上）の頭の高さ（`o.y + 2` まで）を除いた。壁の輪の上、部屋の屋根の高さ以上は今までどおり通れない（建築中に壁へ登らない）。テスト `bed-path.test.mjs`（3 件）。元の規則に戻す変異で落ちる。ブリッジ 745 件通過。

## 4. 「なにも持ってない時は素手で殴り合う」について

昼は、すでにそうなっている: `cleared` の候補は武器なしでも出す（`candidates.mjs` の `clear`）。今回、戦えなかったのは経路が立たなかったためで、素手の戦いが禁じられていたからではない。夜は、`goals.mjs` が武器なし・体力が低いときに「朝まで中で待つ」にしている（暗いうちは次々に湧くため。設計書 89）。これは変えていない。夜も素手で出るべきか、user の判断を待つ。
