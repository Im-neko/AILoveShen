# 143. 判断に迷ったら advisor に意見を聞く

2026-10-09、user: 「llm が判断に困ったら advisor に意見を求められるようにしたいです。advisor のモデルは LITELLM_ADVISOR_MODEL で指定出来るようにしてほしいです」
user の選択: 相談の範囲は「道具の選択だけ」（目標の決定・計画に自動では聞かない）、`ask_advisor` は「いつも道具に出す」（行き詰まりのときだけにしない）。

## 1. 何をするか
- 道具モード（`minecraft.agent.control: tools`）の道具の選択に、調べものの道具 `ask_advisor(question)` を足す。配信の LLM が迷ったときに自分で呼ぶ。`question` に迷っていることと試したことを書く
- 呼ぶと、迷った時に LLM が見ていたプロンプトそのもの（状況・直近の道具の記録）と質問を、別のモデルに渡して助言を書かせる（`Advisor`、用途 `advice`）。助言は 300 字以内の日本語で、次にどの道具をどの引数で呼ぶか、失敗が続く理由
- 助言は直近の道具の結果として次の選択に出る。従うかは LLM が決める（advisor は道具を呼ばない）。答えない・時間切れ・空のときは失敗の結果を返すだけで、ステップは続く
- 調べものと同じ扱い: 1 ステップの調べもの 5 回の中で数え、同じ質問の繰り返しは 2 回目で断る（設計書 99）

## 2. 設定
- `LITELLM_ADVISOR_MODEL`（例: `claude-sonnet-5-5`）→ `llm.litellm.models.advice`。空なら `ask_advisor` は道具に出ない
- `llm.routes.advice: remote`（固定）: ローカルの LLM に聞いても意味がない。`llm.thinking_levels.advice: medium`
- `LITELLM_MODEL` がないとき（リモートがなくローカルで答えてしまう）は、警告を出して advisor を使わない（`factories/text.py` の `has_advisor`）
- モデルを決めるしくみは `LITELLM_CODE_MODEL`（設計書 127 の `models`）と同じ。設定クラスは変えていない

## 3. 決めたこと
- 道具の結果は 300 字で切って次の選択に見せるが、advisor の答えは 800 字まで見せる（切ると読めない）
- advisor に見せるのは LLM のプロンプトそのもの（別の要約を作らない）。LLM が見ていないことで助言しない
- やり方の帳（`abilities.yaml`）には入れない。advisor を決めていないと道具に出ないので、帳が出ない道具を勧めてしまう（同じく出し分ける `look_screen` も帳にない）
- 「決まり」（`TOOL_TEMPLATE`）に使いどきの 1 行は足さない。足すと固定部分が `RULES_BUDGET` を超え（1478 > 1450）、毎ステップ送る文が増えるため、先に削る（設計書 90）。使いどきは道具の説明だけに書いた（ほかの調べものの道具には決まりの行がある）。実際の配信で呼ばれないなら、ここを見直す

## 3.1 毎ステップの費用
- 「いつも出す」ので `ask_advisor` の定義（約 200 トークン、推定）が advisor を決めたときの毎ステップの道具に加わる: ふだん 8,679 → 8,876、行き詰まり 9,313 → 9,510（約 2%）。`test_context_budget.py` に advisor ありの上限を足した（9,300 / 9,980）
- 助言（最大 800 字）は直近の道具に残る間、後のステップのプロンプトにも載る。1 回の相談で後のステップの入力が数百トークン増える

## 4. 見送ったこと
- 目標の決定（`goal`）・計画（`plan`）で、失敗後や行き詰まりにコードが自動で聞く（user の選択で今回はしない）
- 1 時間あたりの回数の上限（`rewrites_per_hour` のような）。今は 1 ステップ 5 回と同じ質問の拒否だけ。費用が増えたら足す
- 助言に従った結果の記録（助言が当たったか）

## 5. テスト
`test_advisor.py`（質問と状況が用途 `advice` で渡る、空の質問、失敗と空の答えは失敗の結果、道具の出し分け、`has_advisor`）、`test_tool_control.py`（道具の選択から advisor に届き、答えが直近の道具に出る、advisor がなければ出ない）、`test_game_prompt_template_builder.py`（advisor の答えは切らない、助言のプロンプト）。実機の LiteLLM（`claude-sonnet-5-5`、用途 `advice`）で、行き詰まった状況と質問に 3.4 秒、307 字で答えた。
