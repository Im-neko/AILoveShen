# 105. 死を教訓にする・夜は死に場所へ取りに行かない

2026-10-07、user: 「なんか死んでない？」→「直して」（3 件）→「そのへんの判断は LLM が良い感じにやったり、知見を貯めて学習してほしい」→「C にしたい。一方で死んだ時だけでなく、コメントでの指摘等も教訓として入れておきたい。これは元から仕組みとしてなかったっけ？」
（`logs/bridge.log` 10:30〜10:33Z、`logs/generations`、`data/lessons.json`）

## 1. 起きていたこと

10:30 に、夜になった境で整地（`level`、268 秒の 1 回の行動）が止まらず、家の北 13 m でゾンビ 3 体・スケルトン・クリーパーに囲まれて死んだ（体力 20 → 0 を 75 秒）。復活の 3 秒後に「死んだ場所に持ち物を取りに行く」手（`recover_items`）が出て、素手で夜の外へ出て、同じ場所の手前でまた死んだ。計 3 回（溺れの 1 回を含む、1 時間弱）。

教訓帳（設計書 35）は動いている（100 件。視聴者の指摘 22 件、失敗 78 件）が、**死に触れる教訓は 0 件**だった。96 回死んでいる。

## 2. 原因

`play.py` の `_decide_goal`: 失敗の分析（`diagnosis` / `remedy` / `lesson`。設計書 27）は、`_no_progress(reason)`（行き詰まった・進まない）のときだけスキーマに入った。死んだときは `" died and "` で、`_no_progress` に入らない。`purpose` は `goal_after_failure`（深く考える）なのに、スキーマに `lesson` の欄がなかった。生成ログで確認した（10:33:50〜10:34:29 の 6 回の決定に `diagnosis` も `lesson` もない）。さらに、復活すると位置・時間帯・体力が変わる（夜の外で死んでも、復活後は「家の中、体力 20」）ので、教訓の「どんなときか」を、決定の時点の観測から作ると正しくならない。

## 3. 決めたこと（C）

### 3.1 死を教訓にする（学習側）
- ブリッジが、死んだ瞬間の様子を 1 件にまとめる（`death-report.mjs`）: 時間帯、場所（家の中・地下・外）、家のドアからの距離、体力の落ち方（何秒で、何回、種類ごとの合計）、そのときの行動。受けたダメージは `installDamageLog` の `onDamage` で直近 90 秒だけ覚える。`/observe` の `last_death`（`state.lastDeath`）で渡す
- Python: 死んだとき（`" died and "`）も、失敗の分析のスキーマにする（`died=True`: `lesson` を必須、やり直し `retry` は選べない）。プロンプトに「死んだときの様子」の欄（`describe_death`）を足し、原因の分析と、次からどうするかの教訓を必ず書かせる
- 教訓の状況（`time` / `place` / `body`）は、死ぬ前の様子から取る（`death_situation`）。`source` は `death`。LLM が `lesson_when` を書けば、それを条件にする
- 視聴者のコメントの指摘は、元からある（`learn_from_viewer`。設計書 35）。変えていない

### 3.2 夜は死に場所へ取りに行かない（規則側）
`recoverTripOk`（`candidates.mjs`）が、夕方と夜は偽を返す（地上でも地下でも）。落とし物は 5 分で消えるので、夜に死ねば取り戻せない（受ける損）。昼に死んだときは、今までどおり（地下は武器と行きの松明がそろっているときだけ）。LLM が自分で `goto` で死に場所へ行くことは止めていない（判断は LLM に任せる）。

## 4. 入れなかったもの（user の選択: C）
- 反射の `go_home` を、体力が低く家が近いときに優先する規則
- 夕方に、長い外の作業（整地など）を止めて帰る規則
どちらも、判断を LLM と学習に任せる方針と反するので、まず教訓がたまるかを見る。今夜も、夜に外で整地を続けている場面があった（10:57）。繰り返すなら、改めて相談する。

## 6. 残ったこと
- 実機で、次の死で教訓が書かれるか（`logs/bridge.log` と `data/lessons.json` に `source: death`、`ended: died`）、夜に死んだあと「取りに戻る」が出ないかは、未確認
- 教訓の質は LLM 次第（今ある「進まない」失敗の教訓も、「遠すぎると中断する」のように一般的すぎる）。死の教訓が思い出されて効くか（`helped` / `failed`）は、数日見る
- 「取りに戻る」を止めた分、昼に死んだときも、素手のまま行く危険は残る（地上の昼は今までどおり）
