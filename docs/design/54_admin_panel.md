# 54. 管理画面（配信中の操作）

ユーザー（2026-09-29）: 「web で管理画面を作りたい。配信中に任意の言葉を喋らせたり、途中で介入する指示を出せるように。喋らせる文章はプリセットを作成・保存・使用できるように（配信のはじめとさいごの挨拶など）」。

決めたこと（ユーザーに確認）: 介入の指示は**配信者の指示として扱う**（視聴者の頼みと同じ仕組みで、上限なし・最優先）。アクセスは**このマシン（127.0.0.1）からだけ**（トークンなし）。

## 構成

- ページと API は目標ボードと同じサーバーの `/admin`（`presentation/web/admin.py` `AdminPanel`、`admin.html`）。OBS のブラウザソースには入れない（配信画面に映さない）
- **喋らせる**: `POST /api/admin/say {text}`。視聴者への返事と同じ優先度（HIGH、実況より先）、感情は Jev が選ぶ（`say_reply`）。実況の重複判定（`SpokenLines`）は通さない（言わせたいことを言う）。読み上げは待たず（長い文で画面が固まらない）、会話の記録には実況として残す（`MessageType.COMMENTARY`。次の返答が言ったことを知っている）。読み上げがオフなら `spoken: false` で、画面がそう言う
- **プリセット**: `SpeechPresets`（`application/use_cases/presets.py`）+ `JsonPresetStore`（`data/presets.json`、`stream.presets_path`）。見出し・本文（500 字まで）・分類（挨拶など）、200 件まで。追加・編集・削除・「喋らせる」・「上の欄に入れる」、分類で絞り込み。変わるたびに保存
- **介入の指示**: `POST /api/admin/instruct {text, reply}`。`LLMService.generate_response(..., producer=True)` = 視聴者の返答と同じ経路（返答 → 頼み → 大目標）で、送り主は「ディレクター」。違い: ①プロンプトに「視聴者ではなく運営の指示。従う。今・すぐなら when=now + rethink」、②大目標は自分の大目標（`suggested_by=ディレクター`、視聴者の頼みの上限・1 人 1 つに数えない）、③荒らし対策の rethink の間引きを受けない、④kind は request。今やるなら小目標を次の切れ目で決め直す。`reply` が真なら、その返事（今やることの一言）を喋る
- **小目標を決め直させる**: `POST /api/admin/rethink {reason}` = `session.request_rethink`（指示なしで切る）
- **目標ツリー**（2026-09-30、ユーザー: 「大中小の目標をツリー構造で全て確認できるように。『いまの様子』とは別で。普段は折りたたんでてよい」）: 「いまの様子」の下の、閉じた `<details>`。`GET /api/admin/state` の `tree`（`goal_tree`: 目標ボードの `goals_snapshot` を最終目標 → 大目標（済み・取り下げ含め全部）→ 中目標 → 計画の小目標（前提は子）に組む。ノードは `key` / `layer`（mission・objective・job・goal）/ `label` / `state` / `notes`（理由・条件・進み具合・頼んだ人・終わった理由）/ `children`）。いまの小目標は、計画の中の小目標と同じならそこに「いまの小目標」の印、なければ、それが仕える大目標の今の中目標の下（中目標がなければ大目標の下）。生存のための小目標は最終目標の直下。小目標がどの中目標のものかは持っていないので、今の中目標に置く。開き閉じは `key` ごとに覚え、3 秒ごとの描き直しで戻らない（初めは、最終目標と今の大目標・中目標だけ開く）。`goals_snapshot` の `goal` に `objective_id` を足した
- 「今の様子」（小目標・大目標）は 3 秒ごとに読む。「送ったもの」は直近 30 件（メモリのみ）

## 守り

- ループバック以外のクライアントは 403（ホストを外に向けても）。`Host` / `Origin` がこのマシンでなければ 403（DNS リバインディングや別サイトのページからの送信）。書き込み（POST / PUT / DELETE）は `X-Admin-Request: 1` が要る（別のオリジンは CORS の許可なしには付けられない）
- トークンはない: 同じマシンで動く別のプログラムからは叩ける。外の PC やスマホから開きたくなったら、ここにトークンを足す（今はしない）

## 限界

- 指示が「今すぐ」でも、Gemini / ローカルモデルが条件に書けなければ断る（返事にそう出る）。指示の返事を作る間、`/api/admin/instruct` は返らない（数秒〜数十秒）
- 喋らせた文は、読み上げの再生が終わるまでの間は「送ったもの」にだけあり、キューの中身は見えない
