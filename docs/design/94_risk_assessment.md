# 94. リスク評価: 禁止を減らし、危なさと失うものを数字にして LLM に見せる

2026-10-07、user: 「絶対禁止はいまどんなものがあるか列挙してもらえますか？基本的にゲームプレイなので絶対禁止は無くても良いかなと思っています」→「行動に出る前にリスクを下げる対応は必要です。安全圏に移動してから作業や所持品をチェストに入れてから外出、装備を整えてから戦闘。一方で所持品も元から特にないなら戦うリスクもそこまで高くない。判断基準にリスク評価を盛り込むとより柔軟なゲームプレイになる」→「順に全部やってみて」。

## 1. 問題

外に出てよいかを、ブリッジが 3〜4 か所で別々に二択で決めていた。

| 場所 | 規則 |
|---|---|
| `candidates.mjs` `ground()` | 避難中（家の中で、夜か、ドアの 8 m 以内に敵）は外の手を候補から外す |
| `tools.mjs` `callTool` | 同じ条件で道具を断る |
| `home.mjs` `leaveHome` | ドアの前の敵がいれば出ない |
| `goals.mjs` `cleared` | 夜は武器と体力 14 以上がなければ出ない |
| `runner.mjs` | 夕方・夜になったら（夜の手以外は）止める |

どれも持ち物、体力、敵の強さを見ない。素手で土 1 個の配信者が、昼にピリジャー 1 体で 1 時間以上家に閉じこもった（2026-10-07）。しかも断りは台帳に 5 分残り、LLM には敵の様子も外された候補も見えなかった。

## 2. リスクの計算（`minecraft-bridge/src/risk.mjs`）

`assessRisk(bot, state)` が 1 か所で `{ level, score, danger, stakes, value, factors, advice }` を返す。

```
danger = 体力 + 満腹度 + 時間帯 + 近くの敵（装備で割り引く）+ 家から遠い
score  = danger × 失うものの重み
```

- 体力: 18 以上 0、14 以上 1、10 以上 2、6 以上 4、それ未満 6。満腹度 6 以下 1、0 で 2。夕方 1、夜 2
- 敵: 16 m 以内の敵対モブ。種類の脅威（クリーパー 3、ピリジャー 2、ゾンビ 1…）× 距離（6 m 以内 1、10 m 以内 0.7、16 m 以内 0.4）。武器（剣の格、斧は 0.75 倍）と着ている防具で、合計を最大 6 割まで割り引く（着ていない防具は数えない: 防具の欄は 5〜8）
- 失うもの（死んだら落とすもの）の重み: 値打ちが 2 未満 0.4、8 未満 0.7、それ以上 1。値打ちは道具・防具（格で決まる。ダイヤのツルハシ 15）と、鉄・ダイヤ・バケツなどの少数のもの。土・丸石・食べ物・松明は 0。何も持たなければ 0 でなく 0.4（死んで戻る時間は失う）。ただし夕方・夜に敵が近いときは 1（§7）
- level: score 2 以上 medium、4 以上 high、7 以上 extreme
- `advice` はリスクを下げる手: 値打ちのある物は先にチェストへ、体力が低ければ食べる・休む、剣がなければ作る・持つ、クリーパーは近づけない

数字は仮。配信の死亡の記録で調整する（§5）。

## 3. 何を変えたか

LLM に見せる:
- `/observe` の `risk`（`index.mjs` の `extra.risk`）→ Python の `_format_risk`（`stream_context.py`）が「外に出る危なさ: 高い（…）。出る前に: …」の 1 行を状況に出す。家の中でも、外に出たときの危なさを出す

二択の禁止を、危なさが **extreme** のときだけ止めるに変えた（`risk.mjs` の `SHELTER_LEVEL`。`none` にすれば止めない）:
- `home.mjs` `shelterOf`: `sheltering` は「家の中 かつ（risk が extreme、またはドアの前にクリーパー）」。夜かどうか、敵がいるかどうかだけでは避難にしない。`leaveHome` も同じ判定を使う（`why` に risk を添える）。クリーパーだけは数字に関わらず外に出さない（§4）
- `candidates.mjs`: 外の手を外す条件が上と同じ。外したときの注記（`withheld`）に risk の理由と、先にすることを書く。ドアの前の敵を避ける壁の出口（`exit_wall`）は、外に出てよいときも選択肢に出す（昼）
- `tools.mjs`: 道具の断りが risk の理由つきになる（`staying inside: going out is too dangerous right now (risk extreme (…)). …`）。`attack` で敵と戦うことは今までどおりできる
- `goals.mjs` `cleared`: 夜に武器がないと目標にできない規則（`makeGoal` の例外）と、武器・体力 14 の規則（`evaluate`）を、risk に置き換えた。extreme なら出ない。値打ちのある持ち物を持っていれば、戦いに出る前にチェストへ預ける（今まで夜だけだったのを、昼も）。武器がなくても、素手で出る手は出す
- `runner.mjs`: 夕方・夜になったら止める規則は、risk が high 以上のときだけ止める（元気で、失うものもほとんどないボットは、夕方も続ける）。深い地下は今までどおり止めない

## 4. 変えなかったもの（まだ禁止のまま）

入力の検証、技術的な限界、クリーパーが近いときの家のドアのそばでの近接戦と帰宅、ドアの前にクリーパーがいるときの外出（`shelterOf` の `creeper`、`cleared` の `EXPLODES`、`CREEPER_HOME_REASON`）、水や溶岩をせき止めているブロック、溶岩・砂・洞窟の安全、畑の地面と未熟な作物、建築中のものの保護（`demolish: true` / `override: true` でも壊せない・置けないもの）、反射（`reflex.mjs` の割り込みと素手の戦いの体力 12 / 8）、暗くて松明がない・空腹・体力が危ないときの中断、夜に木を探して歩く手（`explore`）を出さない規則（`goals.mjs`）。

## 5. 保護の上書き（`override`）

`dig` にだけあった `demolish: true`（保護された家・建物を壊す）の対に、`place` / `use_item` / `move_furniture` に `override: true` を足した。保護（`protectedReason`）と、断られた台帳（`refusalAt`）を通り越す。置く先が物でふさがっている、立っている、家具の置き場がないなど、物理的な断りは残る。断りの文に `override: true` を書いて、LLM が気づけるようにした。

## 6. 確かめたこと・限界

- **発端の場面（昼、家の中、土 1 個、素手、ドアの前にクリーパー 4.5 m とピリジャー 5.8 m）は、この変更では変わらない。** クリーパーがドアの前にいる間は、`shelterOf` が避難にし、`cleared` も出ず、壁の出口（`exit_wall`）か待つしか残らない。クリーパーが去る・倒れるか、ピリジャーだけのときは、risk が低いので外の手が出る。クリーパーも外に出してよいか（爆発で壁が壊れる損と、閉じこもる損のどちらを取るか）は user の判断待ち
- 断りの文は LLM へ 300 字で切られる（`TOOL_RESULT_CHARS`）ので、`describeRisk` は先にすること（最大 2 つ）を前に、短く書く（`risk.test.mjs` が最悪の場合でも 300 字に収まることを確かめる）
- 敵なしの夜は `medium` 止まり（体力が満タンなら 2 点）で、外に出られる。体力 5 の素手の配信者が夜に敵 3 体の外に出る場合、(6 + 2 + 3) × 0.4 = 4.4 で `high` だが `extreme`（7 以上）にならず、断られない。死んだら素手で再び出る往復になりうる。調整は `WEIGHT.nothing`（0.4）と `LEVEL_AT`

- ブリッジ `npm test` 全件、`pytest` 全件。`risk.test.mjs`（6 件）、`shelter.test.mjs`・`tools.test.mjs`・`runner.test.mjs`・`station.test.mjs`・`upgrade_fight.test.mjs` は、危なさが低い（外に出る）・極めて高い（止める）の両方を確かめるように書き換えた
- **実機は未確認。** 配信中のブリッジは再起動するまで古いコードのまま。再起動後に見ること: 昼・夜に元気で何も持たないとき家の外に出ること、ダイヤの道具を持って体力が低いときに止まり、理由に risk が出ること、`risk` の行がプロンプトに出ること
- 閉じこもりの時間が減ると、**死ぬ回数は増えうる**（特に夜、素手で外に出る）。調べ方: 死亡の記録（`state.deaths`、`logs/` の死亡）のうち、外に出たとき `risk` が何だったか。`tools/refusal_report.py` の「夜の籠もり」が減ること。数字（敵の重み、体力の段、失うものの境）はここで調整する
- 剣・斧と着ている防具は失うものに数えない（預けない物。`strength` で敵の割引に使う）
- 夕方・夜の中断を high 以上にしたので、**値打ちのある物を持って敵のいない夜に歩く手は、止まらない**（medium 止まり）。反射（敵が来たら）と体力の中断で守る

## 7. 夜に敵が近いときは重みを下げない（2026-10-07 追記）

実機（再起動後 26 分）で、夜に素手で外へ出て 3 回死んだ（持ち物を取りに出る・`attack`）。何も持たない（重み 0.4）と、夜に敵 2 体でも 1.6 の `low` で、外に出る手が止まらなかった。

- 夕方・夜に敵が 1 体以上近くにいるときは、失うものがなくても重みを 1 にする（`risk.mjs`）。昼の素手の殴り合いは 0.4 のまま
- 効く範囲（体力満タン・素手・夜）: 敵 1 体 `medium`、2 体 `high`（外に出られる）。体力 10・満腹度 5 で敵 3 体、または体力 6 で敵 3 体は `extreme`（外に出る手を止める）。**体力満タンの 2 体は止まらない**
- 止めきれない分は、`SHELTER_LEVEL` と `LEVEL_AT`、時間帯の項で調べる。実機で死亡の記録と `risk` を突き合わせて決める
