# 158. 視聴者の頼み・助言には基本的に従う

2026-10-10、user: 「コメントの指摘を拒否しがちなのなんとかしたい。指摘には基本的に従ってほしい。夜だからベッド置いてって言っても朝になったら置くの一点張りでおかしい」

## 1. 起きていたこと
- 21:36 から 21:37 にかけて、ねこかもの「ベッド設置して」「夜を越すためにベッドが必要だよ」に、4 回とも「朝になってから家の中に置くね」と答えた。中目標 `placed(bed, home)` は `when=next` で後ろに入り、夜の小目標 `through_night` は朝まで待ち続けた。ベッドは持っていて家の中にいた。夜に寝るためのベッドを、朝まで置かない食い違い
- 直前の namatmg の「夜なんだから今すぐベッド置いて寝て朝にすればいいじゃん」にも、「夜に空いた場所に置くと危ない」と事実に合わない理由を返して、断る側に流れた
- 1 回目の返事は `request: none`（約束だけ）で、差し戻されて 2 回目に `accept` へ直るが、`when=next` のまま。夜の規則（`prompt_template_builder.py`「夜に家の中で待っているとき〜後回しにしない」）は文があっても守られなかった
- 設計書 153 §6 で足した `not_better`（考えたうえで採らない答え）は、実機で一度も選ばれず、「採らない」を認める側の道を足しただけだった。今回の方針（基本は従う）とは逆向き

## 2. 直したこと
| 件 | 内容 | 場所 |
|---|---|---|
| 基本は従う | 返答の規則に「基本は従う」を足した。断ってよい理由は危ない・書けない・事実が違う・上限だけで、「今の作業が先」「今のやり方でよい」「あとで」は理由にならない。今できるなら `when=now`、そうでなければ `when=next` にして、いつやるかを言う | `prompt_template_builder.py` |
| 待っている間にできる頼み | 小目標が `through_night` / `at_home`（待っているだけ）のとき、家に置く物（`placed(…, home)`）の頼みを `when=next` にした答えは差し戻す（`deferred_while_waiting`）。3 回直らなければ、返答は直せないが、行動は `when=now` にする（設計書 159 で外した: 文はあとで結果に合わせて書き直す）。外に出る頼み（木を切る、探検）は夜に今やらない | `generate_response.py` |
| `not_better` を外す | 設計書 153 §6 の `DeclineReason.NOT_BETTER` と、その差し戻し文・規則を外した。断る理由は元の 5 つ（cannot / wrong / unsafe / off_mission / limit）だけ | `goal_vocabulary.py`、`generate_response.py`、`prompt_template_builder.py` |

## 3. 確かめたこと
21:36 のプロンプトで実機のモデル（claude-haiku-5-5）に試した。差し戻し後の 2 回目は、ねこかもの 2 件で 5/6 が `accept` + `when=now`（変更前は 4 回とも `when=next`）。1 回目は `none` が多いが、それは今までどおり差し戻される。

## 4. 直っていないこと
- 返事の文が「朝になったら置くね」のまま、行動は `when=now` になる場合がある（言葉と行動の食い違い。約束の確認 `PromiseCheck` は「家に置く」を拾うが、時間の言い回しは見ない）
- `placed(…, home)` 以外の、待っている間にできる頼み（クラフトなど）は、規則の文だけで、コードでは強制していない
- 事実に合わない理由で断る（namatmg の「夜に空いた場所に置くと危ない」）は、`wrong` の確認が「今していること」との照合に頼る。ブリッジの状態との照合はしていない
