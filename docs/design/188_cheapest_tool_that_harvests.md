# 188. 採るのに要る道具は、採れる一番安いものを使う

2026-10-18。鉄のつるはしが、ダイヤの前に 2 度折れた（05:20 前後と 08:34）。そのたびに鉄インゴット 3 個と生の鉄の掘り直しが要り、01:05〜04:42 の防具集めと合わせて、7 時間強ダイヤに届かなかった。

## 1. 原因

`chooseTool`（`primitives.mjs`）は、採るのに要る道具（石にツルハシ）の中から「一番速いもの」を選んでいた。石を掘るのは木 < 石 < 鉄 の順に速くなるので、鉄のつるはしを持っていれば、階段・坑道・枝（数百ブロック）をすべて鉄のつるはしで掘る。鉄のつるはしの耐久は 250 なので、採掘場 1 本で使い切る。ダイヤ鉱石（鉄以上でないと採れない）に着く前に折れる。

## 2. 変更

採るのに要る道具は、採れるものの中で一番安い（木 < 石 < 金 < 鉄 < ダイヤ < ネザライト）ものを使う。壊れかけは後回し（安いものが壊れかけなら、高いものに回す）。同じ階級なら速い方。高い道具は、安い道具では採れないブロック（ダイヤ鉱石には鉄）のために取っておく。

要らない道具（原木に斧、土にシャベル）の選び方は変えない（素手より速いもののうち一番速いもの）。

掘る速さは落ちる（石を鉄で掘ると 0.38 秒、石のつるはしで 0.56 秒）。採掘場 1 本（数百ブロック）で数分の差で、鉄のつるはしを作り直す手間より小さい。

## 3. テスト・未確認

`tools_choice.test.mjs`: 石・鉄鉱石は石のつるはし、ダイヤ鉱石は鉄、安い道具が壊れかけなら高い道具。ブリッジ 1101 通過。実機では未確認（再起動後、鉄のつるはしの耐久が石の採掘で減らないこと）。
