# 115. 崩れた畑を直す

2026-10-08、user: 「農地が崩れたら直すようにしたいです」→（a）穴・丸石・土に戻った農地でよい、（b）「守っちゃうと修正が効きにくくなるので掘るコストを高くして欲しい」、（c）「土は街の外からとってきてほしい」

## 1. 何が崩れるか
畑（`wheat_farm` など）は、作物のマスの地面が耕せる土（`dirt` / `grass_block` / `dirt_path`）で、耕地になっていて初めて使える。崩れ方は 3 種類:
1. 穴（地面が空気になった）: 爆発、土集め、穴からの脱出の掘り。
2. 耕せない固いブロックになった（丸石・石）: 穴を丸石で埋めた跡。`till` は「nothing to till … the ground is cobblestone」で断る。
3. 耕地が土に戻った: 水が届かなかった・踏まれた。今の `till` が耕し直すので、足すものはない。

## 2. 直し方（新しい手は作らない）
2026-10-08 に調べたところ、1 は畑の整地（`farmLevel`、設計書 75）がすでに土で埋める（深さ 8 まで）。詰まっていたのは 2 だった: 整地は「高さが合っていれば、そろっている」と見て、床の高さの丸石を直す対象にしなかった。そこで `repair_farm` のような新しい行動を足さず、整地を広げた（同じ目的の仕組みを二つ持たない）。
- `leveling.mjs` `farmCellWork`: 作物のマスの地面が、耕せず、壊してよい固いブロック（自然の地形か、置いた丸石）なら、その 1 マスを `cuts` と `fills` に入れる（掘って土で埋め直す）。置いた物（かまど、チェスト）は壊さない。水のマスは対象でない。
- `primitives.mjs` `level`（畑）: 埋めるのは土（`dirt` / `coarse_dirt`）だけ。丸石で埋めると、そのマスはまた耕せない。埋めるマスに花や草があれば、先にどける（「the block is still red_tulip」で置けなかった: 項目 6）。丸石も掘れる。
- `goals.mjs`: 目標 `farmed` も、崩れた畑があれば、耕す・まくより前に整地（`level`）を手にする（これまでは `facility` の目標だけが整地した）。道具が要れば作り、土がなければ「街の外から集める」と書いて土を目標にする（`farmLevelStep`、`facility` と共通）。

## 3. 掘る費用（b）
畑の作物のマスの地面を掘る経路探しの費用を `FARM_DIG_COST = 30` にした（`facilities.mjs` `onFarmGround`、`primitives.mjs` の `exclusionAreasBreak`）。0 は無料、100 以上は掘れない。30 は、掘らずに 30 ブロックほど回る方を選ぶ重さ。禁止にしないのは、直す手を妨げないため（user の指示）。閉じた所から出る行動（`ROCK_ESCAPE`: `climb_out`、`dig_in` など）は、安全のために今までどおり掘れる。畑の上のブロック（作物）は対象にしない。

## 4. 土は街の外から（c）
ブリッジに街の境界はなかったので、こう決めた: 街 = 家・建物・すべての施設の `box`（畑・植林場・採掘場を含む）の外側 `TOWN_MARGIN = 6` マスまで（`facilities.mjs` `inTown`）。土（`dirt` `grass_block` `coarse_dirt` `podzol`）の掘る場所を選ぶ `digTargets` は、外、街の中、畑の地面の順に並べる（`world.mjs`）。近い順の 64 個に街の土だけが並ばないよう、土のときは 512 個から探す。
- 禁止ではなく順序: 外の土が `DIG_RADIUS`（32）の中になければ、街の中の土を掘る。
- 土の目標は `dirt` 一般なので、畑の修理のためだけでなく、土を集めるときは必ず街の外が先になる（camp、足場の土も）。

## 4.1 追記: 階段の入口の記録で穴が直されなかった（2026-10-08、実機）
畑が 64/65 マスで約 30 分止まった。残り 1 マスは足元が空気の穴 (24,69,-209) で、整地（`columnWork`）が「quarry stairs」として飛ばしていた。`state.quarry.shafts` に、あとから畑の水のマスになった (24,70,-207) の古い入口が残り、`onShaftTop` が周囲 3 マス（畑 81 列のうち 49 列）を階段の入口として埋めない決まりだった。
- 入口が施設の box の中にある階段は、あとから施設が建って入口がなくなったものとして数えない（`quarry.mjs` `liveShafts`。整地、続きから下りる階段、観測の `quarry.shafts`）。
- 畑の設計したマス（四角の中）は、階段の入口のそばでも直す（`columnWork` の `stairs: false`）。入口のまわりの畑の外の列（まわり 2 マス）は今までどおり埋めない。
- 保存された記録は消さない（見るときに除く）ので、移行は要らない。実際の `state.json` の畑で、穴が 1 列として検出されることを確かめた。

## 5. 未対応
- 作物のマスにできた水源は直さない（`place_water` の中の汲み戻しだけ。設計書 113）。
- 外の土が遠いと、歩く時間が増える（街の中の土より遠い）。
- LLM の道具 `dig` は座標指名なので費用の対象外（畑の地面を指名されれば掘る）。
