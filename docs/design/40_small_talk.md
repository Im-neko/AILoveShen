# 設計書 40: 雑談の幅と、自分について話したことを覚える

## 1. きっかけ

ユーザー（2026-09-27）:「もっといろんなジャンルの雑談を許容するようにしたい。LoL の話題を振られたら答えるようにしたい。但し、一貫性を保てるように自分の話をする時は記憶に残しておいて」。決めたこと: LoL での自分の設定は書かず、話しながら決めて覚える。覚えたことはワールドを作り直しても残す。

実際の返事（`logs/promises`、2026-09-27）: 「クレッド対面ってシェンだとどうしてる？」→「それってLoLのシェンのことかな？私はMinecraft実況者のシェンだから、そっちの戦い方は詳しくないんだよね！」。キャラクター設定とシステム指示が Minecraft の実況者の枠だけで書かれていて、Gemini は知っているのに話を避けていた。

## 2. 仕組み

- システム指示（返事の `reply` / `reply_requests` 共通）に「## 雑談」: Minecraft 以外の話題（LoL などほかのゲーム、アニメ、食べ物、日常）にも自分の好みや意見を交えて乗る。「Minecraft の実況者だから分からない」とかわさない。はっきり知らないことは言い切らない。自分のことは「自分について話したこと」に従い、食い違うことは言わない。まだ話していないことはキャラクターらしくその場で決めてよい。配信スタイルに「ほかのゲームや配信の外の話題の雑談も楽しむ」
- 返事の JSON に `self_facts`（[{topic, fact}]、任意）: 「自分について話したこと」にない自分のことを言ったら書く。前と変わったことも同じ話題で書く。世の中やゲームの一般的な事実は書かない（システム指示の「## 自分の話（self_facts）」）
- `SelfFacts`（application/use_cases/self_facts.py）: 話題ごとに 1 つ（空白と大文字小文字を無視して同じ話題なら置き換える）、話題 30 字・内容 120 字まで、120 件まで（超えたら長く話していないものから忘れる）。変わるたびに `JsonSelfFactStore`（`data/self_facts.json`、`twitch.self_facts_path`）に保存。ワールドの作り直しでは消さない（教訓帳・名前の読みと同じ）
- 返事の本文の先頭に「## 自分について話したこと」（変わりにくいので先頭。26 §4 のキャッシュ）
- 覚えるのは使った返事からだけ（差し戻した返事からは覚えない: 名前の読み・教訓と同じ `_learn`）

## 3. 確かめたこと

- テスト: `test_self_facts.py`（覚える・置き換える・覚えない形・多すぎたら忘れる・JSON で残る・返事のプロンプトに出して返事から覚える）、`test_prompt_template_builder.py`（本文の先頭、システム指示の規則）
- 本物の Gemini（2026-09-27、プロンプトと JSON スキーマだけ）: 上のコメントに、シェンで W を使ってショートトレードする、と答えて覚えた。「LoL のメインは？」→ シェン（覚えた）、「シェン以外は？」→ ガリオ・ポッピー（前の話に合わせた）、「最近見てるアニメは？」→ ダンジョン飯

## 4. 決めなかったこと・あとで

- 実況（commentary）には出していない（自分の話はコメントへの返事で出るもの）。実況で自分の好みを話すようになったら足す
- 返事がテキストだけの道（セッションがないとき）は、見せるだけで覚えない
- 件数が増えたら全部を毎回出すのをやめ、コメントに関係するものだけを選ぶ（今は 120 件まで全部）
