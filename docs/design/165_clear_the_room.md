# 165. 家の部屋のいらないブロックを片付ける

2026-10-11、user: 「部屋の中にまだたくさん石や余計な板材が残ってます。これ壊せるようにならないですか？」

## 1. なぜ壊せなかったか
家の中のブロックは保護されていて、`dig` は `demolish: true` を付けないと断る。整地（`level`）も家の列は残す。LLM が自分で 1 つずつ座標を選んで `demolish` で掘るしかなく、(a) 閉じ込められた間は `No path` で掘れなかった（設計書 163 で、手が届けば掘れるようにした）、(b) 掘るべき座標を LLM が全部は把握できず、ベッドの隣の 1 つ 1 つを掘る手間が残った。

## 2. 変更
- `room-clear.mjs`（新規）: `strayBlocks`。家の部屋（床の高さから壁の高さ `design.wall_height`、既定 3 まで、`home.min` 〜 `home.max`）にある、片付けるブロックを、ボットに近い順に返す。片付けるのは自然の地形（土・草ブロック・石など）、丸石、板材・原木。家具（ベッド・チェスト・作業台・かまど）、松明、ドア、階段、ガラスなどは残す。計画（`state.plan`）が置くと決めたブロックで、正しく置かれているものも残す（計画の場所でも違うブロックなら片付ける）。壁は部屋の外なので触らない
- 候補 `clear the stray blocks out of the home (N: cobblestone x6, …)`（`verb: clear_room`）: 家の中にいて、片付けるブロックがあれば出す（`candidates.mjs` の `clearRoomUp`）
- 実行 `clear_room`（`primitives.mjs`）: 近い順に全部掘る。遠ければ近づき、経路がなくても手が届けば掘る。最後に落とし物を拾う。掘れなかったものが残る、または片付けるものがなかったときは、5 分間は候補に出さない（`clearRoomBlockedUntil`）
- 表示: 「家の中のいらない石や板材を片付ける」（`action_label.py`）

## 3. 注意
- 床の高さより下（部屋の床の地面）と、部屋の外（壁、玄関、玄関の外）は触らない。玄関の草ブロックや外の丸石は別（整地・玄関の仕事）
- 計画にない造作（置いた階段や板の家具など）は、板材・原木なら片付ける。家具を板材で作っていた場合は壊す可能性がある
