# 157. 壊して作り直すときは更地にする・建物の下を掘らない・閉じた空洞の設計を止める

2026-10-10、user: 「あと建物壊して直す時は一度更地にしてから作り直すようにして欲しいです。今くちゃくちゃになっちゃってます」
設計書 155 の調査の 3・4 件目と合わせて。

## 1. 起きていたこと
- `base_house`（9×9×9、塔つき）は、床の下の穴、貫かれた床・天井・塔、置き先に残った原木・板で、壊れた跡の上に新しい壁を置く形になり、跡と新しいブロックが混ざっていた。壊して作り直す手は、`dig {demolish: true}` を 1 つずつ使うしかなく、更地にする手がなかった
- 内側のセル (152,80,-447) へ着けない失敗が 6 回続いたあと、経路探索が床下の土を掘り下げて、建物の下の閉じた穴に入った。「内側が閉じている」とは返らなかった
- 設計に、塔の 3×3×1 の空洞（y=85）が、全面の丸石の床と天井に挟まれて、入る道も出る道もなく入っていた

## 2. 直したこと
| 件 | 内容 | 場所 |
|---|---|---|
| 更地にして作り直す | `build_next {name, reset: true}`（`reset_build`）: 建物の底面の四角（建物の外・となりの家や建物には触らない）を、建物の床の層の下の地面の高さにそろえる。建物のブロック・保護された壁・チェストなどはすべて壊し（`level` の `demolish`、設計書 154）、穴は土で埋める。置いた記録（`plan.seen`）を捨てるので、次の `build_next` は最初のブロックから置く。もう更地なら掘らずに記録だけ捨てる。大きすぎる建物（半径 16 を超える）は断る | `primitives.mjs` `reset_build`、`tools.mjs` `build_next`、`leveling.mjs`（`box`） |
| 建物の下を掘らない | 経路探索の掘る費用: 名前付きの建物と建てている家の底面（まわり 1 マス）の真下、床の層より下 6 段は、歩きながら掘らない。出る・帰る行動（`ROCK_ESCAPE`）は除く | `builds.mjs` `underBuild`、`primitives.mjs` `configureMovements` |
| 着けない理由 | 建物の中のセルへ歩いて着けない失敗に、「壁が閉じているなら、ドアを置く・壁の1マスを `demolish` で開ける、または `build_next {name, reset: true}`」を添える。`site blocked by …` にも `reset` を添えた | `build.mjs` `walkToSpot`、`siteBlocked` |
| 閉じた空洞の設計を止める | `registerBuild` で、外（箱の外の全面、ドアのマスは通れる）からつながらない空洞が 3 マス以上ある設計を、理由つきで差し戻す（設計は既に3回まで書き直す）。屋根のない箱、窓の隙間、ドアで外とつながる部屋は通る | `builds.mjs` `sealedPockets` |

## 3. 直していないこと
- 今の `base_house` の状態は直さない（`build_next {name: base_house, reset: true}` を LLM が選ぶ）。設計そのもの（塔の空洞）は、更地にして作り直すと同じものを建てる: 設計を直すには建物の名前を替えるか、設計し直す手が要る
- 家（`state.home` と家の計画）を壊して作り直す手: 家はベッド・チェスト・ドアの記録と結びついていて、家の修理（設計書 88）が別にある。名前付きの建物だけ
- 「階段のない2階」など、空洞はつながっていても歩いて着けない設計（空洞のつながりだけ見る）
- 経路探索が建物の下を掘らなくても、内側へ着けないなら失敗する（その先は LLM が、ドアを置く・壁を開ける・更地にする、から選ぶ）
- 実機（ブリッジの再起動後）
