# 166. 前の家（半壊・廃屋）を更地にする

2026-10-11、user: 「壊れてる家、半壊してる家を更地にする方法って今ある？なければ一緒に追加して」

## 1. 事実（調査）
- あったもの: `level {where, radius, demolish: true}`（座標と半径を指定して、保護された家・建物も壊して整地。設計書 154）、`build_next {name, reset: true}`（名前付きの建物の底面を更地にして、置いた記録を捨てる）
- なかったもの: 引っ越しで残した前の家（`state.formerHomes`）を更地にする手。座標を調べて `level` を使うことはできるが、(a) 壊しても前の家の記録（`formerHomes`、チェストの記憶）が残り、保護の範囲・ドアの扱い・ランドマークが「家がある」ままになる、(b) 壁の外 1 周まで含めた範囲と床の高さを LLM が自分で出す必要がある
- 半壊の家は、新しい家を建てて引っ越す（`settleHome`）と前の家として残る。壊れた現在の家は、地面が直せなければ別の場所に建て直す（`goals.mjs` の `ruined`）ので、その跡も前の家になる

## 2. 変更
- 道具 `clear_site`（名前なし。設計書 167 で `clear_old_home` を名前つきに広げた）: 一番近い前の家を選び、手 `clear_former_home` にする。前の家がなければ断る（住んでいる家は対象外）
- 手 `clear_former_home`（`primitives.mjs`）: 前の家の部屋に壁の外 1 周を足した底面の四角を、家の床の層の高さにそろえる。`reset_build` と同じ流れ（`level` の `demolish` と `box`）: 壁・屋根・床・家具を壊し、穴は土で埋める。底面の外には触らない。全部そろったら、前の家の記録とそのチェストの記憶を外す。そろわなければ失敗にして記録は残す
- 表示「前の家を更地にする」、`abilities.yaml` の `demolish` に追記
- 道具の定義の上限を +120（設計書 90）。`clear_site` は設計書 167 で `name` を足した（計画に合わない建物・畑）

## 3. 注意
- チェストの中身は、壊すと落ちて拾われる（`level` が 8 個掘るごとに拾う）。先に `withdraw` で出すのが確実
- 前の家の床の層より上の高い屋根・塔は、`level` が続く限り掘る（設計書 164）
- 現在住んでいる家は壊せない。引っ越すか、建て直しが済んで前の家になってから
