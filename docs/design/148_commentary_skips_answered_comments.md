# 148. 実況は、返事済みのコメントにもう一度触れない

2026-10-10、user: 「同じコメントに複数回反応してるかも」

## 1. 起きていたこと
- チャットの返事は 1 コメントにつき 1 回（`ChatResponder` は取り出したコメントを戻さない）。二重に返しているわけではない
- 返事のあとの**実況**が、同じコメントにもう一度触れていた（`data/logs/ailoveshen-dev.log`）
  - 10/10 17:34:01 よもすえさんの挨拶に返事 → 17:34:07 と 17:34:31 の実況が、またよもすえさんに礼と別れの挨拶
  - 10/10 17:34:45 「声変わりましたか？」に返事 → 約 4 分半後の 17:37:59 と 17:39:10 の実況が「声が変わって聞こえたかな？」
  - 10/9 18:12:57 ねこかもさんの植林場の提案に返事 → 18:13:10 と 18:13:29 の実況が提案への礼をもう一度

## 2. 原因
- 実況のプロンプトは会話の最新 10 件（`history_limit`）を、時間も返事か実況かの区別もなく `よもすえさん: …` / `あなた: …` と並べる（`format_messages(messages)`、`now` なし）。実況は十数秒おきに出るので、コメントと返事が数回分の実況のあいだ履歴に残る
- 実況の決まりは「直前の自分の発言を繰り返さない」だけで、返事済みのコメントを扱う決まりがなかった。「視聴者が見ていることを意識した発言」から、最新のコメントを拾って名前を呼ぶ

## 3. 直したこと
- 実況の決まり（`COMMENTARY_RULES`）に追記: 「最近の会話」で視聴者のコメントのあとに自分の発言が続いていれば返事済み。その人の名前を呼んだり内容にもう一度触れたりしない
- 履歴の書き方は変えていない（`[N秒前]` や「〜への返事」を実況にも付ける案と、返事済みのコメントを実況の履歴から外す案は、user の指示で見送り）

## 4. 直していないこと
- 指示をモデルが守るかに頼る。履歴の書き方は「コメント → あなた」の並びだけが手がかり。守られなければ `[N秒前]` と返事の宛先を実況にも付ける
- 目標の決定のプロンプトの会話（`play.py` `recent_messages`）も同じ書き方だが、今回は見ていない
