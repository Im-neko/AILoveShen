## 2. 決めたこと（user の答え: 腰を据える作業は家の中のみ、鉱石は採掘場の壁に露出したものだけ）

### 2.1 精錬・調理は家の中のかまどだけ

- `findFurnace(bot, state)`（`primitives.mjs`）: 家があれば、家の部屋の中のかまどだけ（`inHomeRoom`）。家がまだないときだけ、
  近くのかまど（地下では使わない）。`knownFurnace`: 近い家のかまど、なければ家のかまど（遠ければ歩いて行く）。
  `state.lastFurnace` は家がないときだけ
- 置く: かまど類（furnace / blast_furnace / smoker）は家の中だけ（`stationSpots`、道具 `place` は `stationRefusal` で断る）。
  家の外にいるときは、`place` の葉の候補が `go home to place the furnace inside the house`（`go_home`）になる。
  作業台は、建築予定地への仮設など地上の昼の作業を残して、**地下でだけ**置かない（user の答えは「かまどや作業台」
  だったが、作業台は立ち止まる作業でなく既存の仮設の機能があるので地下だけにした。要確認）
- 使う: `smelt` の行動は、家の外のかまどを断る（`smelt` の道具、候補、記憶のかまども同じ: `furnaceWith` /
  `smeltingCounts` に `accept` を渡し、家のかまどだけ数える。地下で置いたかまどに残った「焼いているもの」は数えない）
- 家がまだないとき（序盤）は、地上なら今まで通り。地下はどちらも断る
- **精錬の待ちは中断できる**（確定していたバグ）: `tendFurnace` の待ちループが毎回 `signal.throwIfAborted()` を見る。
  反射やダメージの中断が、焼き終わるまで待たされない（かまどは `finally` で閉じ、焼いているものは記録に残る）

### 2.2 採掘は採掘場の中で（ブランチマイニング）

調べた定石（ブランチマイニング）: 鉱石の高さまで階段で下り、一直線の幹（高さ 2、幅 1）を掘り、その脇に 3 マスおきに枝を
掘る（枝の間に岩が 2 マス残り、枝の壁の面が一番多く見える）。幹に松明を置く。見えた鉱石だけ掘り、鉱石脈はつながりを追う。
鉱石の高さは設計書 68 のまま（`ORE_Y`）。

- 形（`mineCells` の `branch`）: 東西の坑道（長さ 32、危なければ 24・16・12・8 に短く、本数を減らす）に、`BRANCH.spacing`
  （3）おきに左右へ長さ `BRANCH.length`（10）の枝（最後の 1 マス手前まで）。枝は坑道をすべて掘ってから、入口に近い順に
  左右ひとつずつ、付け根から先へ（どのセルも先に空けた隣に立って掘れる）。セルの `part` は枝ごとに一意
  （`branch_east_5_a`）。東西がだめなら南北。枝を持つ設計は `layout.sealing: true`、`branch_length` を持つ。
  LLM が `facility(mine)` で設計する採掘場は枝なし（今まで通り）
- 松明は幹だけ（階段 12 段、部屋 1 本、坑道 8 マスおき）。枝には置かない（1.18 以降のモブの湧きは明るさ 0 だけで、
  幹の松明が枝の奥まで届く）
- **枝単位の打ち切り**（`stopMine`）: 枝のセルで危ないもの（水・溶岩・岩盤・落ちる砂利・封じ切れない洞窟）に当たったら、
  その枝の先だけを外して `dig_mine` は掘り続ける（結果に `branches cut short for danger: …`）。階段・部屋・坑道は今まで通り
  そこから先すべて
- **探している鉱石が壁に出たら止まる**: `dig_mine`（`sources` を持つ）は 3 セルごとに `oreShowing`（solver と同じ `digTargets`:
  空気に面し、届き、断られていない）を見て、出たら `…shows in the wall at x,y,z: dig it` で返す。1 回で少なくとも 3 セルは掘る
- **掘り尽くしたら新しい採掘場**: `minePlan` の「底にいて壁に鉱石がない」は `make`（`exhausted` = その採掘場）。`make_mine` が
  `layout.exhausted` の印を付け、`minesAt` はもう当てにしない。入口は今まで通り前の入口と同じ行に揃える
- `TOLERANCE` は 16 → 8（坑道と枝は底の 2 マスの高さしか見えない。y 32 の採掘場で y 16 の鉄を探さない）
- **経路探索は、採掘場のほかの深い岩を掘らない**（`protectedRock`、`configureMovements` の `exclusionAreasBreak`）:
  自分で建てた家があるとき、家の床より `SURFACE_DEPTH`（10）以上下の岩・鉱石（`ROCK`）は、採掘場のセル以外は壊さない。
  歩いて行ける所（洞窟）は通る。岩越しの鉱石は `No path` になり、既存の拒否の台帳（5 分）に入る。`go_home` / `surface` /
  `recover_items` / `dig_in` / `leave_burrow` / `flee` / `sleep_at` / `exit_wall`（`ROCK_ESCAPE`）は、閉じた所から出られなく
  ならないよう掘ってよい。家がない・見つけた拠点（仮の宿）のときは今まで通り（`dig_down`、設計書 64）

## 3. 空洞に出たら丸石で塞ぐ（`sealing.mjs`、user: 「ブランチの途中で空洞に出くわしたら、手元の丸石で道・壁・天井を作って」）

通路（坑道・枝・部屋のセル。幅 1、高さ 2）を囲む面 — 床、天井、4 方の壁（高さの数だけ）— のうち、岩でなく空いているもの
（洞窟）に丸石（cobblestone / cobbled_deepslate）を置いて塞ぐ。そうしないと洞窟のモブが通路に入ってくる。

- 順に掘り進むので、置く面の隣には前のセルの同じ面（固い）があり、置くときの「面を借りる隣」になる。床は前のセルから、壁と天井は
  セルの中へ入ってから。置いた面が次の面の隣になるので 3 回まわす
- 掘る前に `openings`（空いている面）を数え、手元の丸石が足りなければ**掘らずに**その枝を打ち切る（洞窟と通路をつなげない）。
  足りるなら掘り、掘ったあと塞ぐ。塞げなかった面が残れば、前のセルから通路のセル自体を丸石でふさぎ（`plugCell`）、その枝を
  打ち切る
- もう空いている（洞窟の）セルも、`mineStatus` が済みと数えない: 枝を持つ採掘場は、セルが**空いていて、かつ囲まれて**
  （`cell.sealed`）初めて済み（階段は除く）。`dig_mine` が点検して印を付け、洞窟の空きセルは掘らずに塞ぐ
- 床の穴（`a cave or a drop under`）は、枝を持つ採掘場の坑道・枝では危ないとして切らず、丸石で埋めて通る（`mineDanger` の
  `sealable`）。水・溶岩・岩盤・落ちる砂利は今まで通り切る。設計時の坑道の安全確認は今まで通り（洞窟を避けて設計する）
- 結果に `walled off N cave openings with cobblestone (floor, walls and ceiling)`
- 丸石の出どころ: 石を掘って出る分（階段・坑道・枝）。整理（`tidyUp`）は丸石を 16 まで持たせるので、洞窟の大きさによっては
  足りず枝を打ち切る（足りるまで持たせる量を増やすかは、実機で見てから）
