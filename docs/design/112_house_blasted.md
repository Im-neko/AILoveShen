## 1. 起きていたこと
13:48Z に家（6x6x4、115 ブロック）が完成した。14:14:04〜10Z に、ドアの前（(-112,68,-128)）でクリーパーが 2 回爆発した（ダメージ 11.3 と 4.7）。ドア、南の壁の一部、室内の南側の床が吹き飛び、ドアの前は 7 ブロック下（y61〜63）のクレーターになった。14:25 に坑道で溺れて死に、ベッド（家の中）に復活したボットは、残った北側の床の上に取り残された。

外に出る行動（`goto`、`explore`、`dig` など）は、実行の前に家の中のドアの前（`home.inside`）へ歩く（`leaveHome`）。その床がなく、`goto` が「No path to the goal!」を 0 秒で返し続けた。1 時間以上、どの目標も進まなかった。

## 2. 前に書いた原因の訂正
最初は「土集めが家の床を掘った」と書いたが、ログからは裏付けられなかった。家の床（y67）の掘りは 0 件で、掘ったのは家の下（y61〜66）の土だけ。爆発の記録（`[damage]` の「unknown … an explosion?」と creeper）が、14:14 のドアの前にある。家の下を掘ったことが爆発の被害を大きくしたかは分からない。このため、「家の下を掘らせない」直しは、この件の対策としては入れていない。

## 3. 直したこと（脱出）
- `doorRouteOk`（`home.mjs`）: ドアの道が使えるか。内側のドアの前に足元の地面があり、ドアのセルと外のセルの下に 3 段以内に地面がある。
- `planLeave` / `leaveHouse`（`primitives.mjs`）: 外に出る行動の前に、ドアの道が使えれば今までの `leaveHome`。使えなければ、壁を掘って出る（`exitSpots` を、外の足元が `EXIT_DROP` = 3 段まで低くてもよい形に広げた）。出たら壁を閉じる（閉じられなければ、壁の穴を直す手 `repair_wall` が残る）。外が 3 段より低ければ、出口がないと理由を付けて失敗にする。
- `runner.mjs` は `leaveHome` ではなく `leaveHouse` を呼ぶ。

## 4. 残っていること（出たあと）
- 家は使えないまま: ドアの前が 7 ブロックの穴で、床の南側もない。`go_home` は毎回失敗し、ベッドは家の中なので、死ぬたびにこの家の中に復活して同じ状態になる。
- 壊れた家（床、ドア、壁）を検知して埋め戻す手がまだない（`fillDoorstep` は深さ `DOORSTEP_DEPTH` までの穴だけ）。user に判断を仰ぐ。
- ドアの前でのクリーパーの爆発（`CREEPER_HOME_REASON` はクリーパーを家へ連れて行かない、だけ）。
