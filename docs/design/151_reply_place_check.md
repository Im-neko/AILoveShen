2026-10-10、user: 「地上に出た後もコメントでの返答は地上にいない感じになってたりして整合性がやっぱ微妙そうです。この辺なんとかならないですかね？ハーネスの実装を見直してほしいです」
（`logs/generations/gen-20261010T100406Z.jsonl`、`data/logs/ailoveshen-dev.log` 19:32〜19:33）

## 1. 起きていたこと
- 19:19 に家の中へ入ったあと、19:32:49 の「次何するの？」への返事が「石のツルハシを作るために作業台までの道を探して、丸石を集めながら地上へ出る道をつなげていくね」だった。実際は家の中で、石のツルハシ（残り 110/131）を手に持っていた
- 19:33:21 の「もう地上に出てるよ」への返事も「ここから家まで戻って…」。すでに家の中

## 2. 原因（プロンプトを実測）
- プロンプトの事実は正しかった（「今いる場所: 家の中」、手に stone_pickaxe）。モデルが、**古い材料に引きずられた**
  - 「最近の会話」の返事が 4 往復とも「地下から出る」話（14〜26 分前）
  - 「自分のメモ」5 件がすべて「経路が通らない・地表へ出る道を探す・石のツルハシは作業台と板が要る」（地下で困っていたときに書いたもので、数日ぶん有効）
  - 大目標が「なし」で、「次は？」に答える現在の計画が小目標 `through_night()` だけだった
- 返事には、持ち物の食い違いだけを見る `ReplyFactCheck` はあったが、**今いる場所**を照らす仕組みがなかった。実況・一言は `SpeechGuard`（`SpeechCheck`）が家の中か外かを照らすが、チャットの返事は通っていなかった。また地下か地上かは、実況でも照らしていなかった

## 3. 直したこと
| 件 | 直し | 場所 |
|---|---|---|
| 地下・地上を照らす | 「地下にいる・地上に出ていない」「地上に出た」と言っているかを Jev に聞く 2 問を足した。状態は観測の `underground`。実況・一言の照合にも効く | `speech_check.py` `CLAIMS_UNDERGROUND` / `CLAIMS_ON_SURFACE` |
| 返事を照らす | `ReplyFactCheck` が、持ち物の確認のあとに、返事の場所（家の中・外、地下・地上）を `SpeechCheck.check(place_only=True)` で照らす。食い違えば、事実を添えて書き直させる（既存の再試行の枠。最後の試しは話す）。返事は次の予定を答えてよいので、小目標との照合は入れない | `reply_facts.py`、`factories/llm.py` `create_fact_check` |
| 返事の決まり | 「次は何をするの」は、今の小目標と大目標から答える。過去の会話や自分のメモの予定は古いことがある | `prompt_template_builder.py` `REPLY_RULES` |

## 4. 直していないこと
- 古い材料そのもの: 返事のプロンプトの「自分のメモ」と古い返事の往復。返事に使うメモを絞る、状況が変わったら外す、は未着手（効果を見てから）
- 大目標が空のとき「次は？」に答える材料がない
- 返事の照合が Jev 頼み（Jev が答えない・確信度が低いときは、そのまま話す）。持ち物の確認と同じ
- 小目標の食い違い（石のツルハシを持っているのに「作る」）は、返事では照らしていない
