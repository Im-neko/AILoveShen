# 137. 畑の水のマスの水は、バケツを満たす水源に数えない

2026-10-09、user: 「どう？しばらく動かしてるけどなんか詰まってる？というか畑つくり続けてる？」→「なおして」→ 「でも緊急で汲むことはあります。置く場所をミスった時等。というかこの辺もfreeなら良い感じにLLMが判断できないんですか？」

## 1. 何が起きていたか（`logs/bridge.log`、ワールドを `inspect` で確認）
- 04:00 台以降の約 70 分で、耕す手が 211 回、97 マス。同じマスを最大 8 回耕していた。作物のないマスは `dirt` / `grass_block` に戻り、作物のあるマスは `farmland` の水分 0 だった。畑に水がなく、乾いた耕地が土に戻っていた
- 水がない理由: 目標 `have(water_bucket)` の `fill` 候補（`fill the bucket with water`）が、`waterSource`（一番近い流れていない水源）に畑の水のマスを選んでいた。
  - 05:00:53 畑 1 の水のマス (44,74,-478) を汲んだ（今は `air`）
  - 05:04:02 畑 2 の (44,77,-462) に水を置き、1 秒後の 05:04:03 に同じ水を汲み戻した（そのあと整地が土で埋めて、今は `dirt`）
  - 置いた水を次の水のマスのために汲む輪で、どの畑にも水が残らない

## 2. 直したこと
- `world.mjs` `waterSource`: `waterAt(state, p)`（畑の水のマス）を水源から外す。畑の水のマスしか近くになければ、水源なし（`explore` で池や川を探す）
- `tools.mjs` `use_item`: 空のバケツで畑の水のマスを汲むときは、断らず、free では `not enforced: this water is the water cell of the farm <名前>: taking it dries the farmland there (fine to take back a misplaced one; put it back with the water tool afterwards)` を結果に添える（`advise`。`BRIDGE_GUARDS=standard` のときだけ断る）

## 3. 断らず警告にした理由（user の指摘）
置く場所を間違えたとき、置いた水を急いで汲み戻すことがある。そこで断ると手が打てなくなる。一方、ソルバーの自動の候補は、LLM が「この水はどこの水か」を知らずに選んでいた（候補の名前は場所を言わない）ので、そこは判断に任せず水源から外す。LLM が使う道具（座標を指定する `use_item`）は、警告を見て判断できる。

## 4. 直していないこと
- 水のない畑を耕し続ける（`till` の 574 行の `advise` は、種が足りないときの警告だけで、水のない畑そのものは止めない）。水が戻れば止まる輪ではあるが、水の手が失敗し続けると同じ空回りになる
- 畑 1・畑 2 に水は戻っていない（バケツは空か満タンか未確認）。配信の再起動後、`facility` の水の手が畑 1 の水のマスを埋め直すかは未確認
