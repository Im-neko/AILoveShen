# 140. 眠る前にベッドの隣まで歩く

2026-10-09、user: 「いまなんでベッド使えてないんだろう」→「なおして」

## 1. 何が起きていたか
- 引っ越した家（エコー・スマイル・コテージ）で、夜になるたびに `sleep in the bed` が `failed: the bed is too far`（0 秒）で失敗していた（`logs/bridge.log` 08:52〜）
- ベッドは `(157,79,-459)` 足側・`(158,79,-459)` 頭側の東向きで、奥の壁沿いに横向き。入口の内側は `(158,79,-456)`
- Mineflayer の `bot.sleep` は、ボットの足元（切り捨て）が頭側から「南へ 2 マス、北へ 3 マス…」の箱の外だと `the bed is too far` を投げる（`node_modules/mineflayer/lib/plugins/bed.js`）。この向きでは z ≤ -457 まで。入口の内側 z=-456 は 1 マス足りない
- `sleep`（`primitives.mjs`）は `enterHome` のあと、すぐ `sleepOn` を呼んでいた。`enterHome` は家の中にいれば歩かず、入るときもドアの内側で止まる。ベッドがドアの正面に伸びていれば内側から届くが、`bedSpot` が選ぶのはその配置を優先するだけで、置けなければ横向きになる
- `sleep_at` / `bed_here` は、ベッドの近くまで歩いてから眠るので、この問題はない

## 2. 直したこと
`sleep` は `enterHome` のあと、ベッドの隣（`GoalNear(bed, 1)`）まで歩いてから `sleepOn` を呼ぶ。すでに隣にいれば歩かない。
テスト: `doorstep.test.mjs`（ドアの内側にいて、奥に横向きのベッドがあるとき、ベッドの隣から `bot.sleep` が呼ばれる。直す前は `(0,65,0)` から呼んで失敗する）。
